- 用 `split()` 把一行文字拆成 List；

## 開始前：想一想

假設程式只接受 `python` 作為答案。有人輸入 ` Python `，人一眼便知道答案正確；程式直接比較時，又會得到甚麼結果？

## 新概念

### 1. 字串方法會產生新結果

字串內的字元不能直接改動。`strip()`、`lower()`、`replace()` 會**回傳一段新文字**，所以必須保存結果或直接接在後面使用。

### 2. 分割、搜尋和組合

`split()` 把文字按分隔符號拆開；`"-".join(items)` 把 List 合併成一段文字。`in` 可以檢查某段文字是否出現，`count()` 可以計算出現次數。

## 跟著做：例子 1——整理一個課程名稱

```python
raw_subject = "  PYTHON Programming  "
clean_subject = raw_subject.strip().lower()

print("原本：", repr(raw_subject))
print("整理後：", clean_subject)
print("是否包含 python：", "python" in clean_subject)
```

### 預期輸出

```text
原本： '  PYTHON Programming  '
整理後： python programming
是否包含 python： True
```

### 逐行解釋

`strip()` 只清除**開頭和結尾**的空格，不會刪除句子中間的空格。`lower()` 把英文字母轉成小寫，令比較時不受大小寫影響。

`repr(raw_subject)` 顯示文字的表示方式，讓前後空格清楚可見。

## 再試一次：例子 2——由逗號清單找出關鍵字

```python
raw_tags = "Python, AI, data, Python"
tags = [tag.strip().lower() for tag in raw_tags.split(",")]

print("整理後的標籤：", tags)
print("python 出現次數：", tags.count("python"))
print("用 / 組合：", " / ".join(tags))
```

### 預期輸出

```text
整理後的標籤： ['python', 'ai', 'data', 'python']
python 出現次數： 2
用 / 組合： python / ai / data / python
```

先用逗號 `split(",")` 拆成多個項目，再逐個 `strip()` 和 `lower()`。這是 List comprehension 的寫法；它把每個 `tag` 處理後收集成新 List。

## 易錯位

### ❌ 忘記保存處理後的文字

```python
name = "  Alex  "
name.strip()
print(name)
```

**原因：** `strip()` 回傳新文字，沒有改變 `name`。

**✅ 修正：** 寫成 `name = name.strip()`。

### ❌ 以為 `strip()` 會刪除所有空格

`"A B".strip()` 的中間空格仍存在。

**✅ 修正：** 只需要清除兩端空格就用 `strip()`；有其他規則時再明確使用 `replace()`。

### ❌ 未整理就直接比較

`"Python" == "python"` 的結果是 `False`。

**✅ 修正：** 對需要比較的輸入套用同一套整理規則。

## 本課小結

1. 字串方法通常回傳新文字，要保存處理結果。
2. `strip()`、`lower()` 令輸入較一致，減少比較錯誤。
3. `split()` 和 `join()` 可在一行文字與 List 之間轉換。
