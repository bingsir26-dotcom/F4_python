## 新概念

### 1. 字串方法會回傳新文字

字串通常不可直接修改。`text.lower()`、`text.strip()` 等會回傳處理後的新字串，應保存或直接使用結果。

### 2. 分割和合併

`split()` 按分隔符號把文字變成 List；`join()` 把多段文字合併。這些方法在清洗資料欄位時很實用。

![字串處理的核心概念：去空格、統一大小寫、替換、分割](/images/lesson-41-strings-advanced.svg)

## 跟著做：例子 1——整理活動報名輸入

```python
raw_name = "  Alex Chan  "
clean_name = raw_name.strip()
raw_subject = "PYTHON"
clean_subject = raw_subject.lower()

print(clean_name)
print(clean_subject)
```

### 預期輸出／結果

輸出 Alex Chan 和 python。前後空格已移除，英文大小寫已統一。

### 逐行解釋

`strip()` 移除頭尾空格；`lower()` 把英文變小寫。原本的變數仍保存原文字。

## 再試一次：例子 2——把逗號分隔的興趣拆開

```python
text = "AI,Python,Data Analysis"
items = text.split(",")

print(items)
print(" / ".join(items))
```

`split(",")` 以逗號分割得到 List；`join()` 在每項之間放入新的分隔文字。

## 易錯位

### ❌ 忘記保存方法回傳值

```python
name = " Alex "
name.strip()
print(name)
```

輸出仍有空格，應寫 `name = name.strip()`。

### ❌ 以為 `lower()` 一定改變中文

`lower()` 主要處理有大小寫的文字；中文本身沒有英文那種大小寫。
