>
> 一個分數可以用一個變數保存；一班同學的分數、遊戲背包的物品、播放清單的歌曲，則需要列表。

## 新概念

### 1. 列表是一個有次序的資料清單

```python
students = ["Amy", "Ben", "Chris"]
scores = [80, 90, 70]
```

方括號 `[]` 表示列表；每一份資料叫做一個**元素**。元素有先後次序。

![列表與索引位置：第一個元素的位置是 0](/images/lesson-05-list-index.svg)

### 2. 讀取列表資料：從 `0` 開始數

```python
scores = [80, 90, 70]

print(scores[0])
print(scores[1])
print(scores[2])
```

輸出是：

```text
80
90
70
```

列表的第一個位置是 `0`，不是 `1`。`scores[0]` 代表「取出 `scores` 中位置 0 的元素」。

### 3. 修改、加入和移除資料

```python
bag = ["藥水", "地圖"]

bag[0] = "大藥水"
bag.append("鑰匙")
bag.pop()

print(bag)
```

執行後輸出：

```text
['大藥水', '地圖']
```

- `bag[0] = "大藥水"`：修改第一個元素；
- `append()`：在最後加入一個元素；
- `pop()`：移除最後一個元素。

### 4. `len()`：列表有幾個元素？

```python
students = ["Amy", "Ben", "Chris"]
print(len(students))
```

輸出是 `3`。`len()` 日後會用來計算平均分，也會告訴我們列表可用位置的範圍。

## 跟著做：例子 1——遊戲背包

```python
bag = ["藥水", "地圖", "火把"]

print(bag[0])
print(bag[2])
print("物品數量：", len(bag))
```

### 預期輸出

```text
藥水
火把
物品數量： 3
```

### 逐行解釋

```python
bag = ["藥水", "地圖", "火把"]
```

建立一個名為 `bag` 的列表，裡面依次有三個物品。

```python
print(bag[0])
```

讀取位置 `0` 的第一個物品。

```python
print("物品數量：", len(bag))
```

`len(bag)` 會計算背包內有多少個元素。

## 再試一次：例子 2——拿到新物品

只在最後加入兩行：

```python
bag.append("金幣")
print(bag)
```

列表會變成：

```text
['藥水', '地圖', '火把', '金幣']
```

現在 `bag[3]` 是甚麼？請先猜再執行。

## 易錯位

### ❌ 把第一個位置寫成 `1`

**錯誤寫法**

```python
students = ["Amy", "Ben", "Chris"]
print(students[1])
```

這會顯示 `Ben`，因為位置 `0` 才是第一個元素。

**✅ 改成這樣**

```python
print(students[0])
```

### ❌ 讀取不存在的位置

**錯誤寫法**

```python
scores = [80, 90, 70]
print(scores[3])
```

這個列表只有位置 `0`、`1`、`2`，位置 `3` 不存在。

**✅ 改成這樣**

```python
print(scores[2])
```

### ❌ 忘記方括號

**錯誤寫法**

```python
scores = 80, 90, 70
```

這不是本課要使用的列表寫法。

**✅ 改成這樣**

```python
scores = [80, 90, 70]
```

## 本課小結

1. 列表用 `[]` 保存多份有次序的資料。
2. 列表第一個元素的位置是 `0`；可用 `list_name[index]` 讀取或修改元素。
3. `append()` 加入最後一項，`pop()` 移除最後一項，`len()` 計算元素數量。
