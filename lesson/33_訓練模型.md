## 新概念

### 1. Loss（損失）

Loss 用一個數字量度預測與真實答案的差距。回歸常用 MSELoss；loss 越低通常代表在目前資料上較接近答案，但仍要看測試資料。

### 2. Backpropagation 與 optimizer

`loss.backward()` 計算梯度；optimizer 根據梯度更新可學習參數。`zero_grad()` 很重要，否則上一輪梯度會累積。

## 跟著做：例子 1——訓練一個簡單回歸模型

```python
import torch
from torch import nn

x = torch.tensor([[1.0], [2.0], [3.0], [4.0]])
y = torch.tensor([[3.0], [5.0], [7.0], [9.0]])

model = nn.Linear(1, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)

for epoch in range(200):
    prediction = model(x)
    loss = loss_fn(prediction, y)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

print(loss.item())
```

### 預期輸出／結果

loss 通常會變得很小。這組資料遵從簡單規律 `y = 2x + 1`，線性模型可逐步學到接近的關係。

### 逐行解釋

每輪都依次做：預測、計算 loss、清除舊梯度、反向傳播、更新參數。`lr` 是 learning rate，控制每次更新步幅。

## 再試一次：例子 2——查看模型對新數字的預測

```python
new_x = torch.tensor([[5.0]])
print(model(new_x).item())
```

訓練完成後，再把新輸入交給模型。輸出應接近 `11`，但因隨機初始和訓練設定可能略有不同。

## 易錯位

### ❌ 忘記 `zero_grad()`

PyTorch 預設會累積梯度；不清除會令下一輪更新混入前面資料的梯度。

### ❌ learning rate 太大或太小

太大可能令 loss 上下跳甚至變大；太小則學得很慢。需觀察訓練過程調整。
