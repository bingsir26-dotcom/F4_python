## 一、選擇題（每題 4 分，共 20 分）

1. Python 是甚麼？

2. 下列哪一個是 Python 的輸出指令？
   A. `input()`　B. `print()`　C. `type()`　D. `len()`

3. 下列哪一個變數名稱是正確的？
   A. `1score`　B. `my value`　C. `student_name`　D. `class`

4. `input()` 的回傳資料型態通常是甚麼？
   A. `int`　B. `float`　C. `str`　D. `bool`

5. 下列哪一個是比較運算子？
   A. `=`　B. `+`　C. `==`　D. `print`

## 二、是非題（每題 2 分，共 10 分）

請寫「對」或「錯」。

1. Python 程式對縮排不敏感。
2. `==` 用來比較兩個值是否相等。
3. 列表（list）中的第一個元素索引是 `0`。
4. `int("5")` 可以把文字 `"5"` 轉成整數 `5`。
5. `while` 迴圈一定只會執行一次。

## 四、程序題（共 50 分）

### 題目 1：輸入兩個數字，計算總和（20 分）

請寫一個程式，讓使用者輸入兩個數字，然後輸出它們的總和。

**要求：** 使用 `input()`、把輸入轉成整數、用 `print()` 顯示結果。

### 題目 2：成績判斷（15 分）

請寫一個程式，讓使用者輸入一個成績，判斷是否及格。

**要求：** 成績大於或等於 60 顯示「及格」；否則顯示「不及格」。

### 題目 3：猜數字遊戲（15 分）

請寫一個簡單的猜數字遊戲。

**要求：** 答案固定為 7；使用者輸入一個數字；猜中顯示「答對了」；否則顯示「再試一次」。
