## 開始前：想一想

寫程式時，你可能覺得「我看得懂」，但當程式少了一個冒號、把 `=` 寫成 `==`，或遇到 60 分這個邊界值時，答案仍然正確嗎？

這課不是只為了得到分數，而是找出下一步最需要補強的地方。

## 新概念

### 1. 測驗可以檢查三種能力

- **讀碼**：看懂變數、判斷和迴圈正在做甚麼；
- **預測**：不執行程式也能先推想輸出；
- **改錯**：根據錯誤訊息和規則修正程式。

### 2. 先追蹤資料，再猜輸出

遇到程式題時，不要只看最後一行。可以在紙上記下變數每次更新後的值，例如 `total` 由 0 變成 5、再變成 12。這樣較容易看出迴圈和條件是否正確。

## 跟著做：例子 1——先預測，再執行

```python
scores = [55, 72, 60]
passed_count = 0

for score in scores:
    if score >= 60:
        passed_count = passed_count + 1

print(passed_count)
```

### 預期輸出／結果

```text
2
```

### 逐行解釋

`passed_count` 由 0 開始。55 不符合條件；72 令它加 1；60 也符合「大於或等於 60」，所以最後是 2。這題的重點是分辨 `>` 和 `>=` 的差異。

## 再試一次：例子 2——找出並修正錯誤

```python
age = input("請輸入年齡：")

if age >= 18:
    print("可以報名")
else:
    print("未滿 18 歲")
```

### 這次改了甚麼？

這段程式會出錯，因為 `input()` 取得的是文字，不能直接與數字 18 比較。修正方法是：

```python
age = int(input("請輸入年齡："))
```

之後的 `if age >= 18:` 才能正確比較數字。

## 易錯位

### ❌ 把比較寫成 `=`

**原因：** `=` 是把資料放入變數；比較是否相等要用 `==`。

**修正方法：** 在 `if` 條件中使用 `==`、`>=`、`<=` 等比較運算子。

### ❌ `if` 後漏了冒號或縮排

**原因：** Python 用冒號和縮排表示「條件成立時要執行哪些指令」。

**修正方法：** `if 條件:` 後面加冒號，下一行程式縮排 4 個空格。

### ❌ 只看一組正常資料

**原因：** 正常案例可能剛好沒有碰到邊界，例如 59 和 60 的差異。

**修正方法：** 每題至少試正常值、邊界值和特殊值。

## 你來做

### 基礎題

不執行程式，先預測以下程式輸出甚麼，再自行執行確認：

```python
number = 7
if number % 2 == 0:
    print("偶數")
else:
    print("奇數")
```

### 標準題

寫一個程式，輸入兩個整數，顯示較大的數；若相同則顯示「一樣大」。請測試 `(3, 5)`、`(8, 8)` 和 `(-2, -1)`。

### 挑戰題

寫一個程式，讓使用者輸入多個以空白分隔的分數，輸出：

- 合格人數；
- 最高分；
- 平均分。

至少測試：全部不及格、剛好 60 分、只有一個分數。

## 本課小結

1. 基礎測驗要同時檢查讀碼、預測和改錯能力。
2. 追蹤變數的變化，能幫助理解條件和迴圈。
3. 資料型態、比較運算子、冒號和縮排都是常見失分位置。
