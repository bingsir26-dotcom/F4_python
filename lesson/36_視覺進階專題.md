## 新概念

### 1. DataLoader：一次處理一小批

圖片很多時，不必一次把所有資料送進模型。`DataLoader` 每次取出一小批圖片，讓程式逐批訓練，也可用 `shuffle=True` 打亂訓練順序。

### 2. 訓練模式和評估模式

- `model.train()`：準備更新參數；
- `model.eval()`：準備作穩定的預測；
- `torch.no_grad()`：評估時不計算更新所需的梯度，節省資源。

## 跟著做：例子 1——用小圖案訓練分類模型

```python
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader

torch.manual_seed(1)

# 類別 0：左半邊亮；類別 1：右半邊亮
left = torch.zeros(1, 4, 4)
left[:, :, :2] = 1
right = torch.zeros(1, 4, 4)
right[:, :, 2:] = 1

train_images = torch.stack([left, right] * 10)
train_labels = torch.tensor([0, 1] * 10)

# 測試圖案保留相同類別，但不是訓練集中完全相同的 Tensor
test_left = left.clone()
test_left[0, 0, 0] = 0
test_right = right.clone()
test_right[0, 3, 3] = 0
test_images = torch.stack([test_left, test_right] * 2)
test_labels = torch.tensor([0, 1] * 2)

train_data = TensorDataset(train_images, train_labels)
loader = DataLoader(train_data, batch_size=4, shuffle=True)

model = nn.Sequential(nn.Flatten(), nn.Linear(16, 2))
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.2)

for epoch in range(10):
    model.train()
    total_loss = 0

    for images, labels in loader:
        logits = model(images)
        loss = loss_fn(logits, labels)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        total_loss += loss.item()

    print("第", epoch + 1, "輪平均 loss：", round(total_loss / len(loader), 4))
```

### 預期輸出／結果

每輪平均 loss 通常會下降。資料很簡單，模型應能很快學會分辨「左半亮」和「右半亮」。

測試圖案仍屬於「左半亮／右半亮」兩類，但不是訓練集中完全相同的 Tensor。這仍是用來理解流程的虛構資料，不代表模型已能辨認真實照片或已有可靠泛化能力。

### 逐行解釋

`TensorDataset` 把圖片和答案配成一筆一筆資料；`DataLoader` 每次提供四筆。`CrossEntropyLoss` 用來比較兩個類別的輸出分數和真正類別。

每個 batch 都依次預測、計算 loss、清除梯度、反向傳播和更新參數。`model.train()` 放在每個 epoch 開始，明確表示現在是訓練階段。

## 再試一次：例子 2——在評估模式檢查預測

**先完整執行例子 1**，再加入以下程式：

```python
model.eval()
with torch.no_grad():
    logits = model(test_images)
    predictions = logits.argmax(dim=1)

correct = (predictions == test_labels).sum().item()
print("測試準確率：", correct / len(test_labels))

for index in range(len(test_labels)):
    print(
        "第", index + 1, "張：真正答案 =", test_labels[index].item(),
        "；模型預測 =", predictions[index].item()
    )
```

這次不只印準確率，也逐筆比較真正答案和預測。若真實專題出現錯誤，便可再顯示那張圖片，尋找圖案模糊、資料太少或類別相似等原因。

## 易錯位

### ❌ 評估時仍在更新模型

若預測測試資料時繼續 `backward()` 和 `step()`，測試資料便偷偷參與訓練，結果不再公平。

**✅ 修正：** 使用 `model.eval()` 和 `torch.no_grad()`，只作預測。

### ❌ 把示範資料的高準確率當成真實能力

本例只有兩種非常規則的圖案；真實圖片會有光線、角度、背景和不同物件。

### ❌ 只展示答對的圖片

錯誤樣本往往最能告訴我們下一步要改善甚麼。

## 本課小結

1. `DataLoader` 把大量資料分成可處理的小批。
2. 訓練和評估是不同階段，評估時不可更新參數。
3. 準確率以外，逐筆比較真正答案和預測才能看見錯誤原因。
