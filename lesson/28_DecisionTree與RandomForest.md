# 第 28 課：Decision Tree 與 Random Forest——用規則作分類

> **本課主題：讓模型把資料整理成一連串可閱讀的條件規則，再認識多棵樹一起投票的做法。**
>
> 決策樹像電腦版的 if／else：先問一個問題，再按答案走到不同結果。Random Forest 則集合很多棵稍有不同的樹，綜合它們的判斷。

## 今課可以做到甚麼？

- 用決策樹從天氣資料產生簡單規則；
- 讀出一棵樹的條件和結果；
- 了解 Random Forest 為甚麼不只看一棵樹。

## 開始前：想一想

決定戶外活動是否改到室內時，最先要問甚麼？

若只用一條簡單規則，可能是「有雨便改室內」。這種一步一步問條件、最後得到結果的思考方式，就是決策樹的基本樣子。

## 新概念

### 1. Decision Tree：把判斷寫成樹狀規則

每個節點是一條條件，例如「雨量 ≤ 0.5？」；最後的葉節點給出類別，例如「戶外」或「室內」。

### 2. Random Forest：很多棵樹一起看

Random Forest 會訓練多棵略有不同的決策樹，再綜合它們的結果。它通常比單棵深樹穩定，但規則也較難完整解釋。

![一棵決策樹用條件得到結果；多棵樹可把結果匯集成投票](/images/lesson-28-trees-forest.svg)

## 跟著做：例子 1——把天氣資料變成一棵規則樹

```python
from sklearn.tree import DecisionTreeClassifier, export_text

# 每一筆輸入是 [雨量（mm）, 氣溫（°C）]
weather = [[0, 18], [0, 23], [0, 29], [1, 17], [1, 24], [1, 30], [2, 20], [3, 26]]
plans = ["戶外", "戶外", "戶外", "室內", "室內", "室內", "室內", "室內"]

tree = DecisionTreeClassifier(max_depth=2, random_state=0)
tree.fit(weather, plans)

print(export_text(tree, feature_names=["雨量", "氣溫"]))
```

### 預期輸出／結果

畫面會顯示類似以下的規則：

```text
雨量 <= 0.50  →  戶外
雨量 > 0.50   →  室內
```

實際排版由套件輸出，但可讀出模型先以「雨量」作判斷。

### 逐行解釋

`weather` 的每筆資料有兩個特徵：雨量和氣溫。`plans` 是我們事先給出的活動建議。

`max_depth=2` 限制樹最多分兩層，令規則保持短小。`export_text()` 把模型學到的樹以文字顯示出來。

## 再試一次：例子 2——讓多棵樹綜合判斷

**先執行例子 1**，再加入以下程式：

```python
from sklearn.ensemble import RandomForestClassifier

forest = RandomForestClassifier(n_estimators=50, random_state=0)
forest.fit(weather, plans)

print("晴天 25°C：", forest.predict([[0, 25]])[0])
print("下雨 25°C：", forest.predict([[1, 25]])[0])
```

`n_estimators=50` 表示使用 50 棵樹。這個例子中，晴天輸出「戶外」，下雨輸出「室內」。

## 易錯位

### ❌ 把樹上的規則當成自然定律

規則只來自目前這八筆虛構資料。真實活動安排還應考慮雷暴警告、場地安全、參加者需要等資訊。

### ❌ 把 Random Forest 想成重複複製同一棵樹

不同樹會從資料中看到略有不同的部分，最後才綜合結果；它不是把同一答案印 50 次。

### ❌ 只因為樹可以很深，就一直增加深度

很深的樹可能記住訓練資料細節。第 27 課提醒我們，仍要看未見資料的表現。

## 本課小結

1. 決策樹以一連串條件作分類，像整理好的 if／else。
2. Random Forest 綜合多棵樹的結果，通常較穩定。
3. 規則是否合理仍要看資料、測試和真實情境。
