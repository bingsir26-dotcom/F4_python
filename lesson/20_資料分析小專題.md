## 開始前：想一想

「我畫了一張圖」不等於「我完成了資料分析」。例如看到某班平均分較高時，我們仍要問：

- 這是哪些資料？有多少筆？
- 平均分較高是否代表每一位學生都較高？
- 圖表真正回答了哪一個問題？

本課會把這些問題整理成一個可重複使用的分析流程。

## 新概念

### 1. 一個資料作品的四部分

1. **問題**：想了解甚麼？
2. **資料**：資料來自哪裡？有哪些欄位？
3. **分析與圖表**：用了甚麼計算、篩選或圖表？
4. **結論與限制**：資料支持甚麼說法？還有甚麼不能確定？

### 2. 先讓程式可重複執行

專題程式應由載入資料開始，而不是假設上一課的變數仍然存在：

```python
import pandas as pd
import matplotlib.pyplot as plt

survey_df = pd.read_csv("class_survey.csv")
```

本課可使用網站提供的 [class_survey.csv](/data/class_survey.csv)，或改用經老師批准、沒有個人私隱的資料。若使用 Google Colab，先下載並上傳 CSV；方法見[資料與 AI 課程執行環境](/資料與AI課程執行環境)。不要把同學全名、電話、住址、帳戶資料等敏感資料放進公開作品。

### 3. 結論要跟證據相配

如果資料顯示「本資料集內，睡眠較多的同學平均分較高」，這是描述你手上的資料；它**不等於**證明「多睡一定令所有人分數更高」。資料分析要清楚分開觀察結果與過度推論。

## 跟著做：例子 1——班級調查資料的平均分比較

下載 [class_survey.csv](/data/class_survey.csv)，並上傳到目前的 Colab／Notebook 工作資料夾，然後執行完整程式：

```python
import pandas as pd
import matplotlib.pyplot as plt

survey_df = pd.read_csv("class_survey.csv")

print(survey_df.head())
print(survey_df.groupby("睡眠類別")["測驗分數"].mean())

average_by_sleep = survey_df.groupby("睡眠類別")["測驗分數"].mean()
average_by_sleep.plot(kind="bar", color=["#87bfff", "#f6b73c", "#63c49a"])

plt.title("不同睡眠類別的平均測驗分數")
plt.xlabel("睡眠類別")
plt.ylabel("平均測驗分數")
plt.ylim(0, 100)
plt.show()
```

### 預期結果

你會看見：

- 調查資料的前五列；
- 按「睡眠類別」分組後的平均測驗分數；
- 一張比較不同類別平均分的柱狀圖。

### 逐行解釋

```python
survey_df.groupby("睡眠類別")["測驗分數"].mean()
```

先把資料按 `睡眠類別` 分組，再只取 `測驗分數` 一欄計算平均。這是在回答：「每個睡眠類別的平均測驗分數是多少？」

```python
plt.ylim(0, 100)
```

固定 y 軸為 0 到 100，避免很小的差距因圖表比例而看似非常誇張。

## 再試一次：例子 2——分析讀書時間和分數

只改問題和圖表：這次觀察讀書時間與測驗分數是否有明顯關係。

```python
import pandas as pd
import matplotlib.pyplot as plt

survey_df = pd.read_csv("class_survey.csv")

plt.scatter(survey_df["每天讀書小時"], survey_df["測驗分數"], color="#4e79a7")
plt.title("每天讀書時間與測驗分數")
plt.xlabel("每天讀書小時")
plt.ylabel("測驗分數")
plt.ylim(0, 100)
plt.show()
```

散點圖中的每一個點代表一筆資料。它有助我們觀察資料是否大致向上、向下，還是沒有明顯規律。

## 易錯位

### ❌ 未看資料就假設欄位名稱

```python
survey_df.groupby("sleep")["score"].mean()
```

**原因：** 本資料的欄位並不是 `sleep` 和 `score`。

**✅ 修正：** 每次換資料集，先執行：

```python
print(survey_df.columns)
```

### ❌ 用圖表取代結論

只交一張圖，讀者仍不知道你想回答甚麼問題、圖表顯示甚麼。

**✅ 修正：** 圖表下至少寫三句：問題、觀察到的數字／趨勢、合理限制。

### ❌ 把相關說成一定因果

「讀書時間較長的資料點常較高」是觀察；「讀書較長一定使成績提高」則未必成立，因為還有其他因素。

### ❌ 忘記資料私隱

如果資料涉及同學，請移除可識別身分的資料，並只在教師同意的範圍內使用與展示。
