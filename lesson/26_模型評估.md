# 第 26 課：模型評估——不要只考已做過的題目

> **本課主題：保留一部分未見資料作測試，檢查模型面對新例子的表現。**
>
> 若模型用自己曾經學過的資料回答問題，就像拿練習題當考試題；高分不一定代表真的學懂規律。

## 今課可以做到甚麼？

- 把資料分成訓練集和測試集；
- 讀出分類模型在新資料上的準確率；
- 用混淆矩陣查看模型把哪類資料弄錯。

## 開始前：想一想

你把十題練習題的答案全部背熟，再用同十題測驗自己，取得 10／10 能否證明你已經懂得做變形題？

模型也需要把一部分資料留到最後，當作它從未見過的測驗。

## 新概念

### 1. 兩組資料有不同工作

- **訓練集**：給模型看，用來學習規律；
- **測試集**：先收起來，最後才用來檢查模型。

![同一份鳶尾花資料分成訓練與測試兩部分，最後比較預測和答案](/images/lesson-26-model-evaluation.svg)

`train_test_split()` 會把資料分開。設定 `random_state=12` 可讓這次分法固定，方便同學在同一條件下比較程式結果。

### 2. 準確率只回答「答對多少」

準確率（accuracy）是「預測正確的數量 ÷ 測試資料總數」。它很有用，但只看一個百分比，仍看不到模型主要錯在哪一類。

## 跟著做：例子 1——用未見過的花朵資料測試模型

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

iris = load_iris()

X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target,
    test_size=0.25,
    random_state=12,
    stratify=iris.target
)

model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)

y_pred = model.predict(X_test)
print("測試準確率：", accuracy_score(y_test, y_pred))
```

### 預期輸出／結果

畫面會顯示一個 0 到 1 之間的數字；例如約 `0.95` 代表這次 38 筆測試資料中，大約 95% 被正確分類。

### 逐行解釋

`load_iris()` 提供一份公開的鳶尾花教學資料，共有 150 筆例子。`iris.data` 是花朵的量度資料，`iris.target` 是已知花種。

`test_size=0.25` 表示約四分一資料留作測試。`stratify=iris.target` 讓三個花種在訓練集和測試集都有大致相同的比例。

`y_test` 是測試集的真正答案；`y_pred` 是模型的預測。只有到這一步才比較它們。

## 再試一次：例子 2——查看模型主要弄錯甚麼

**先執行例子 1**，再執行以下程式：

```python
from sklearn.metrics import confusion_matrix

print(confusion_matrix(y_test, y_pred))
```

每一行代表真正花種，每一列代表模型預測花種。主對角線上的數字是答對的資料；其他位置表示模型把一類花誤判成另一類。

不必急著背矩陣格式。現在先記住：它比單一準確率多提供「錯在哪裡」的線索。

## 易錯位

### ❌ 用同一份資料訓練又測試

這會令模型像背熟原題再考原題，結果通常過於樂觀。

**✅ 修正：** 先分出 `X_train`／`y_train` 和 `X_test`／`y_test`；只用訓練集呼叫 `fit()`。

### ❌ 把一次準確率當成模型永遠的成績

資料分法、資料量和資料代表性都會影響結果。一次測試只是一個檢查起點。

### ❌ 只看準確率而不看錯誤內容

即使準確率高，也應了解錯誤集中在哪一類；有些問題中的某種錯誤後果會更嚴重。
