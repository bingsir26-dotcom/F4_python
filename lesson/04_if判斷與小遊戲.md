# 第 4 課：if 判斷與小遊戲

## 4.1 if 是什麼？

讓電腦做決定

## 4.2 基本語法

```python
if 條件:
```

執行

## 4.3 if else

```python
score = 70

if score >= 60:
    print("及格")
else:
    print("不及格")
```

## 4.4 多重判斷

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

## 4.5 小遊戲：成績判斷

```python
score = int(input("輸入成績："))

if score >= 60:
    print("及格")
else:
    print("不及格")
```

## 4.6 小遊戲：猜數字

```python
answer = 7
guess = int(input("猜數字："))

if guess == answer:
    print("答對了")
else:
    print("再試一次")
```

## 4.7 升級版

```python
if guess == answer:
    print("答對了")
elif guess > answer:
    print("太大")
else:
    print("太小")
```

## 4.8 常見錯誤

❌

```python
if a = 5:
```

✅

```python
if a == 5:
```
