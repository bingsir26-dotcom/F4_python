# 第 4 課：`if` 判斷與小遊戲

> **本課主題：讓程式根據不同情況作出不同回應。**
>
> 遊戲判斷你有沒有答對、商店判斷金幣夠不夠、成績系統判斷是否及格，背後都需要 `if`。

## 今課可以做到甚麼？

完成這一課後，你可以：

- 讓 Python 按條件顯示不同結果；
- 用 `if`、`else`、`elif` 製作成績判斷器；
- 寫出有「太大／太小」提示的猜數字遊戲。

## 開始前：想一想

朋友猜一個神秘數字。假設答案是 7：

```text
猜中時要說「答對了」；
猜得太大時要提示「太大」；
猜得太小時要提示「太小」。
```

如果只用 `print()`，程式每次都會顯示同一句話。Python 怎樣才知道要選哪一句？

## 新概念

### 1. `if`：先問問題，再決定要做甚麼

`if` 後面放一條會得到 `True` 或 `False` 的條件。條件成立時，縮排內的程式才會執行。

```python
score = 72

if score >= 60:
    print("及格")
```

`score >= 60` 的結果是 `True`，所以 Python 顯示「及格」。

![if 判斷流程：條件成立和不成立會走向不同結果](/images/lesson-04-if-flow.svg)

### 2. 縮排是程式的一部分

冒號 `:` 表示「接下來要開始一個區塊」；下方需要縮排的程式，就是條件成立時要做的事。

```python
if score >= 60:
    print("及格")
    print("可以進入下一關")
```

這兩行前面都空了四格，因此都屬於 `if`。

### 3. `else`：條件不成立時怎麼辦？

```python
score = 52

if score >= 60:
    print("及格")
else:
    print("未及格，再努力！")
```

`if` 和 `else` 之中，每次只會執行其中一個區塊。

### 4. `elif`：有多個可能結果

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 60:
    print("C")
else:
    print("F")
```

Python 由上到下檢查條件。找到第一個成立的條件後，就顯示結果並跳過其餘分支。

### 5. 兩個條件可以一起判斷

`and` 表示兩個條件都要成立；`or` 表示其中一個成立即可。

```python
age = 14
has_ticket = True

if age >= 12 and has_ticket:
    print("可以入場")
```

判斷範圍時，`and` 很有用：

```python
if score >= 60 and score < 80:
    print("C 等級")
```

門檻數字要特別小心。`score > 60` 不包括剛好 `60`；`score >= 60` 才包括 `60`。寫完條件後，請特別測試剛好在門檻的值。

## 跟著做：例子 1——及格判斷器

```python
score = int(input("請輸入成績："))

if score >= 60:
    print("及格！")
else:
    print("未及格，再努力！")
```

### 一次示範

```text
請輸入成績：72
及格！
```

### 逐行解釋

```python
score = int(input("請輸入成績："))
```

取得使用者輸入的成績，轉成整數並保存到 `score`。

```python
if score >= 60:
```

問 Python：「`score` 是否大於或等於 60？」記得條件結尾要有冒號。

```python
    print("及格！")
```

這一行有縮排，只有條件成立才會執行。

```python
else:
    print("未及格，再努力！")
```

如果 `score >= 60` 不成立，就執行 `else` 的區塊。

## 再試一次：例子 2——猜一次，給提示

把「及格／未及格」改成三種提示：

```python
answer = 7
guess = int(input("猜一個 1 至 10 的數字："))

if guess == answer:
    print("答對了！")
elif guess > answer:
    print("太大了，再試一次。")
else:
    print("太小了，再試一次。")
```

請分別輸入 `7`、`9` 和 `4`，觀察每次會走到哪一個分支。

> **注意：** 現在程式只讓玩家猜一次；第 7 課學 `while` 後，才會改成「未猜中就繼續問」。

## 易錯位

### ❌ 用 `=` 比較答案

**錯誤寫法**

```python
if guess = answer:
    print("答對了")
```

`=` 是放入資料；比較是否相同要用 `==`。

**✅ 改成這樣**

```python
if guess == answer:
    print("答對了")
```

### ❌ 忘記冒號

**錯誤寫法**

```python
if score >= 60
    print("及格")
```

**✅ 改成這樣**

```python
if score >= 60:
    print("及格")
```

### ❌ 把剛好在門檻的情況漏掉

```python
if score > 60:
    print("及格")
```

**原因：** 分數剛好是 `60` 時，`60 > 60` 不成立，會錯判為未及格。

**✅ 修正：** 規則是「60 分或以上」時，要使用 `>=`。

```python
if score >= 60:
    print("及格")
```

### ❌ 沒有縮排

**錯誤寫法**

```python
if score >= 60:
print("及格")
```

**✅ 改成這樣**

```python
if score >= 60:
    print("及格")
```

## 本課小結

1. `if` 根據條件是否成立，決定是否執行縮排內的程式。
2. `else` 處理條件不成立的情況；`elif` 用於多個條件。
3. `and`、`or` 可組合條件；比較門檻時，要分清楚 `>` 和 `>=`。
4. 比較相同要用 `==`；`if`、`elif`、`else` 的行尾要有 `:`。
