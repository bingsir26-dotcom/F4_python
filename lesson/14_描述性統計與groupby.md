# 第 2 節：描述性統計與分組分析（groupby）

這一節會讓學生由「整理資料」進一步學會「從資料中找答案」。學生會使用平均值、最高值、最低值、中位數等描述性統計，再透過 groupby() 比較不同班別、性別或組別的表現。groupby() 的核心概念是「分組 → 計算 → 合併結果」。pandas.pydata+2

## 1. 學習目標

完成本課後，學生應能：

使用 groupby() 按班級或類別分組。

## 2. 什麼是描述性統計？

描述性統計（Descriptive Statistics）就是用幾個數字，快速描述一大堆資料的情況。

例如，全班有 40 位學生，如果老師想知道全班成績如何，不一定要逐一看 40 個分數，可以看：

平均分：全班大約的表現。

最高分：最好的成績。

最低分：最低的成績。

中位數：中間位置的成績。

標準差：分數是否很分散。

describe() 能產生資料的摘要統計，包括平均值、標準差、最小值、最大值與百分位數，並會忽略缺失值。pandas.pydata+2

你可以跟學生說：

描述性統計就是把很多數據，濃縮成幾個有意思的數字。

## 3. 本課範例資料

先建立一張包含姓名、班級、性別和兩科成績的資料表。

```python
import pandas as pd

data = {
```

## 4. 基本描述性統計

## 4.1 平均值：mean()

平均值可以讓我們了解整體表現。

```python
print(df["數學"].mean())
```

如果要計算平均分欄位的平均：

```python
print(df["平均分"].mean())
```

可以加上文字輸出：

```python
class_average = df["平均分"].mean()

print("全班平均分：", class_average)
```

## 4.2 最高值：max()

```python
print(df["平均分"].max())
```

找出全班最高平均分。

## 4.3 最低值：min()

```python
print(df["平均分"].min())
```

找出全班最低平均分。

## 4.4 中位數：median()

中位數是把所有分數由小到大排列後，位於中間位置的數值。

```python
print(df["平均分"].median())
```

中位數的好處是：如果有一個分數特別高或特別低，它受影響通常比平均值小。

例如：

```python
scores = [60, 65, 70, 75, 100]
```

平均值容易被 100 拉高。

中位數是 70，比較接近大部分學生的表現。

## 4.5 標準差：std()（進階）

標準差可以看出資料有多分散。

```python
print(df["平均分"].std())
```

簡單理解：

標準差小：學生分數比較接近。

標準差大：學生分數差距比較大。

這個概念可以先讓學生知道，不必要求立即深入計算公式。

## 5. 使用 describe() 快速看統計摘要

如果想一次查看數學、英文、總分、平均分等統計資料，可以使用：

```python
print(df[["數學", "英文", "總分", "平均分"]].describe())
```

常見結果包括：

| 名稱 | 意思 |
| --- | --- |
| count | 有多少筆有效資料 |
| mean | 平均值 |
| std | 標準差 |
| min | 最小值 |
| 25% | 第 25 百分位數 |
| 50% | 中位數 |
| 75% | 第 75 百分位數 |
| max | 最大值 |

describe() 的作用是快速產生數值欄位的摘要統計。pandas.pydata+2

你可以跟學生說：

describe() 就像幫資料做一張「健康檢查報告」。

## 6. 為什麼需要分組分析？

只看全班平均，有時看不到不同群組的差異。

例如：

F4A 和 F4B 哪班平均較高？

男生和女生的平均是否不同？

哪個班的數學成績較好？

哪班學生的成績差距較大？

這時就要使用 groupby()。

## 7. 什麼是 groupby()？

groupby() 是 pandas 的分組功能。  
它會先按指定欄位把資料分成不同小組，然後對每組資料分別計算，最後合併結果。pandas.pydata+2

你可以用以下三步講解：

分組（Split）：先按班級把學生分成 F4A 和 F4B。

計算（Apply）：分別計算每班平均分。

合併（Combine）：把每班結果整理成新表格。

你可以跟學生說：

groupby() 就像把全班先分組，再計算每組的結果。

## 8. 按班級計算平均分

```python
class_average = df.groupby("班級")["平均分"].mean()

print(class_average)
```

結果概念：

| 班級 | 平均分 |
| --- | --- |
| F4A | 81.25 |
| F4B | 73.125 |

這代表：

F4A 的平均分是 81.25。

F4B 的平均分是 73.125。

F4A 的整體平均較高。

## 8.1 讓結果更像表格

```python
class_average = df.groupby("班級")["平均分"].mean().reset_index()

print(class_average)
reset_index() 可以把班級名稱由索引變回普通欄位，讓輸出的資料表更容易閱讀。
```

## 9. 按班級計算多個統計結果

```python
class_stats = df.groupby("班級")["平均分"].agg(["mean", "max", "min"])

print(class_stats)
agg() 可以一次對每個群組使用多種統計方法。pandas.pydata+2
```

結果概念：

| 班級 | mean | max | min |
| --- | --- | --- | --- |
| F4A | 81.25 | 89.0 | 71.0 |
| F4B | 73.125 | 93.5 | 56.5 |

## 10. 按性別分組分析

除了班級，也可以按性別分組。

```python
gender_average = df.groupby("性別")["平均分"].mean()

```

結果概念：

| 性別 | 平均分 |
| --- | --- |
| 女 | 87.5 |
| 男 | 66.875 |

教學提醒：小心解讀資料

這個結果只代表「這一小組資料」的情況，不能直接說所有女生一定比所有男生成績好。

你可以提醒學生：

資料量可能很少。

樣本可能不平均。

分組結果不代表所有人都一樣。

這可以自然銜接 AI 課中的「資料偏差與公平性」。

## 14. 常見錯誤

錯誤 1：忘記指定要計算的欄位

```python
df.groupby("班級").mean()
```

這行有時也能執行，但初學時建議清楚指定欄位：

```python
df.groupby("班級")["平均分"].mean()
```

這樣學生更容易知道：  
「按班級分組，計算平均分的平均值。」

錯誤 2：欄位名稱寫錯

```python
df.groupby("班別")["平均分"].mean()
```

如果資料表的欄名是「班級」，寫成「班別」就會出錯。

錯誤 3：把非數字欄位拿去計算平均

```python
df["姓名"].mean()
```

姓名是文字，不可以計算平均。

錯誤 4：錯誤解讀平均值

如果 F4A 平均分較高，不代表 F4A 每一位學生都比 F4B 每一位學生高。  
平均值只是整體摘要，還要看個別資料、最高分、最低分和分布情況。
