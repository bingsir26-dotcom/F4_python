# 第 22 課：由例子學規律——機器學習的第一步

> **本課主題：把「已有答案的例子」交給模型，然後請它估計一筆新資料的答案。**
>
> 機器學習不是魔法，也不是把答案藏在程式裡。它先看一批例子，從中找出規律；之後才對未見過的新資料作出估計。

## 今課可以做到甚麼？

- 把一個生活問題整理成「輸入資料」和「已知答案」；
- 用 `fit()` 讓模型閱讀已有例子；
- 用 `predict()` 請模型估計一筆新資料。

## 新概念

### 1. 先用白話分成兩欄

這一課先記住兩件事：

- **輸入資料**：模型可以看到的資料，例如氣溫；
- **已知答案**：我們已有的結果，例如雪糕售出數量。

機器學習常把輸入資料叫作**特徵**（feature），把已知答案叫作**標籤**（label）。先明白兩欄的角色，比急著背英文名稱更重要。

### 2. 由例子到新問題

![由四筆已知資料開始，模型估計一筆新資料的答案](/images/lesson-22-ml-workflow.svg)

可以把本課流程讀成四步：

1. 準備多筆「輸入資料＋已知答案」；
2. 用 `fit()` 讓模型從例子找規律；
3. 準備一筆新的輸入資料；
4. 用 `predict()` 取得模型的估計。

`model` 是保存這個規律的程式工具。它的預測未必正確，因為它只能根據看過的資料作推斷。

> **環境提醒：** 本單元使用 scikit-learn。Google Colab 通常已經提供；若顯示找不到套件，請使用課堂指定的執行環境。

## 跟著做：例子 1——由氣溫估計雪糕售出數量

```python
from sklearn.linear_model import LinearRegression

# 每一筆輸入都是 [氣溫]；右邊是對應的已知答案
temperatures = [[20], [24], [28], [32]]
sales = [40, 48, 56, 64]

model = LinearRegression()
model.fit(temperatures, sales)

prediction = model.predict([[30]])
print(prediction)
```

### 預期輸出

```text
[60.]
```

### 逐行解釋

```python
temperatures = [[20], [24], [28], [32]]
```

這是四筆輸入資料。現在每筆資料只有一個項目——氣溫；所以每一筆都寫成 `[20]`、`[24]` 這種小 List，再把所有小 List 放在外面的 List 內。

```python
sales = [40, 48, 56, 64]
```

這是每一天對應的已知答案。第一個 40 對應 20°C，第二個 48 對應 24°C，如此類推。

```python
model = LinearRegression()
```

建立一個用來估計連續數字的模型。下一課會更仔細認識它。

```python
model.fit(temperatures, sales)
```

讓模型閱讀輸入資料和已知答案，找出它們之間的規律。

```python
prediction = model.predict([[30]])
```

請模型估計 30°C 時可能售出多少杯。新資料的寫法也要和訓練資料一樣：一筆、只有一個項目的資料，所以寫成 `[[30]]`。

## 再試一次：例子 2——一次估計兩個新日子

**先執行例子 1**，再加入以下程式：

```python
new_temperatures = [[22], [34]]
predictions = model.predict(new_temperatures)

print(predictions)
```

### 預期輸出

```text
[44. 68.]
```

外層 List 裡有兩筆資料：`[22]` 和 `[34]`。因此模型會依次給出兩個估計結果。

## 易錯位

### ❌ 把單一數字直接交給 `predict()`

```python
model.predict(30)
```

**原因：** 模型需要知道這是「幾筆資料」，以及每筆有多少個輸入項目。

**✅ 修正：** 一筆、只有一個輸入項目的資料也要寫成 `[[30]]`。

```python
model.predict([[30]])
```

### ❌ 輸入資料和答案數量不同

```python
temperatures = [[20], [24], [28]]
sales = [40, 48]
```

**原因：** 每一筆輸入資料都需要一個對應答案。

**✅ 修正：** 兩邊的筆數必須一樣。

### ❌ 把模型的估計當成保證

天氣以外還可能有下雨、假日、活動等因素影響銷量。模型沒有看見的資料，不會自動考慮。
