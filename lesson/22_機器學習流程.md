## 新概念

### 1. 特徵、標籤與模型

- **特徵（feature）**：模型用來判斷的資料，例如房屋面積、房間數。
- **標籤（label）**：我們希望預測的答案，例如房價或「垃圾／非垃圾」。
- **模型（model）**：由資料學到規律的工具。

### 2. 基本流程

先準備有答案的訓練資料，讓模型 `fit()`；再把從未見過的新資料交給 `predict()`。模型的預測不一定正確，所以之後還要測試它。

## 跟著做：例子 1——由身高預測鞋碼

```python
from sklearn.linear_model import LinearRegression

# 每一筆資料是 [身高]；答案是鞋碼
heights = [[150], [160], [170], [180]]
shoe_sizes = [36, 39, 42, 45]

model = LinearRegression()
model.fit(heights, shoe_sizes)

prediction = model.predict([[165]])
print(prediction)
```

### 預期輸出／結果

畫面會顯示接近 `40.5` 的數字。這只是示範資料，不能當作真實鞋碼規則。

### 逐行解釋

`heights` 是特徵資料；每個內層 List 代表一位人的一筆資料。`shoe_sizes` 是已知答案。`fit()` 讓模型根據兩者找規律；`predict([[165]])` 要求它估計身高 165 的鞋碼。

## 再試一次：例子 2——一次預測兩筆新資料

```python
new_heights = [[155], [175]]
predictions = model.predict(new_heights)
print(predictions)
```

把一筆 `[165]` 改成兩筆 `[[155], [175]]`，模型便會為每一筆資料各給一個預測。特徵的欄位結構必須和訓練時一致。

## 易錯位

### ❌ 把單一數字直接交給 `predict()`

```python
model.predict(165)
```

**原因：** 模型預期的是「多筆資料的表格」形式。

**✅ 修正：** 一筆、只有一個特徵的資料也要寫成 `[[165]]`。

### ❌ 把預測當成事實

模型只根據訓練資料估計規律。資料太少、有偏差或遺漏重要因素時，預測可能不可靠。
