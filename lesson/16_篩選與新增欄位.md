>
> 上一課你學會閱讀資料表；這一課會用條件找出達標遊戲紀錄，並加入總金幣和平均金幣，讓資料表開始回答問題。

## 今課可以做到甚麼？

- 篩選出符合一個或多個條件的遊戲紀錄；
- 新增總金幣、平均金幣等計算欄位；
- 用資料回答「哪些回合達標？」、「哪個角色總金幣最高？」等問題。

## 開始前：想一想

第一單元你寫過：

```python
if gold >= 60:
    print("達標")
```

如果現在有 40 個遊戲紀錄，難道要手動寫 40 次 `if` 嗎？

### 先猜一猜

```python
game_df["第一關金幣"] >= 60
```

這行程式不會立刻選出紀錄；它會為每一列產生 `True` 或 `False`。你猜 `True` 代表甚麼？

答案是：該列的第一關金幣符合「60 枚或以上」。接著我們便可用這組 True／False 篩選資料。

## 新概念

### 本課起始 cell：先執行一次

若剛開啟新的 Notebook／Colab，先執行這一格。後面的篩選和新增欄位例子都會使用 `game_df`。

```python
import pandas as pd

game_data = {
    "玩家": ["Nova", "Rex", "Mira", "Kai", "Luna"],
    "隊伍": ["紅隊", "紅隊", "藍隊", "藍隊", "紅隊"],
    "第一關金幣": [78, 55, 91, 72, 84],
    "第二關金幣": [82, 70, 88, 69, 90]
}

game_df = pd.DataFrame(game_data)
```

### 1. 篩選和 `if` 的關係

```python
game_df["第一關金幣"] >= 60
```

這和第一單元的判斷概念相同，只是 pandas 一次為整欄資料作比較。

```python
game_df[game_df["第一關金幣"] >= 60]
```

外層的 `game_df[...]` 表示「保留符合條件的資料列」。

### 2. 新增一欄計算結果

```python
game_df["總金幣"] = game_df["第一關金幣"] + game_df["第二關金幣"]
```

右邊先把每個角色兩關的金幣相加，左邊把結果保存到新欄位 `"總金幣"`。

### 3. 同時符合兩個條件

```python
game_df[(game_df["第一關金幣"] >= 60) & (game_df["第二關金幣"] >= 60)]
```

- `&` 表示「而且」：兩個條件都要成立。
- 每一個條件都要用括號包起來。

## 跟著做：例子 1——找出第一關達標紀錄

```python
import pandas as pd

game_data = {
    "玩家": ["Nova", "Rex", "Mira", "Kai", "Luna"],
    "隊伍": ["紅隊", "紅隊", "藍隊", "藍隊", "紅隊"],
    "第一關金幣": [78, 55, 91, 72, 84],
    "第二關金幣": [82, 70, 88, 69, 90]
}

game_df = pd.DataFrame(game_data)
first_level_target = game_df[game_df["第一關金幣"] >= 60]
print(first_level_target)
```

### 預期輸出

```text
     玩家  隊伍  第一關金幣  第二關金幣
0  Nova  紅隊        78        82
2  Mira  藍隊        91        88
3   Kai  藍隊        72        69
4  Luna  紅隊        84        90
```

Rex 的第一關金幣是 55，所以不符合條件，沒有出現在結果中。

### 逐行解釋

```python
game_df["第一關金幣"] >= 60
```

逐一比較第一關金幣欄的每個數字，得到 True／False 結果。

```python
first_level_target = game_df[game_df["第一關金幣"] >= 60]
```

保留比較結果為 True 的資料列，並保存到 `first_level_target`。

```python
print(first_level_target)
```

顯示篩選後的表格。

## 再試一次：例子 2——加入總金幣和平均金幣

先確認已執行本課起始 cell 或例子 1，令 `game_df` 已建立。這次只加入兩欄計算結果：

```python
game_df["總金幣"] = game_df["第一關金幣"] + game_df["第二關金幣"]

3   Kai   141    70.5
4  Luna   174    87.0
```

只改了「新增欄位」這個元素，但原本的資料表現在能回答更多問題。

## 易錯位

### ❌ 用 `and` 連接兩個欄位條件

```python
game_df[(game_df["第一關金幣"] >= 60) and (game_df["第二關金幣"] >= 60)]
```

**原因：** pandas 比較整欄資料時，要使用 `&`，不能使用 Python 單一條件的 `and`。

**✅ 修正：**

```python
game_df[(game_df["第一關金幣"] >= 60) & (game_df["第二關金幣"] >= 60)]
```

### ❌ 忘記條件的括號

```python
game_df[game_df["第一關金幣"] >= 60 & game_df["第二關金幣"] >= 60]
```

**✅ 修正：** 每一個比較條件都用括號包起來。

```python
game_df[(game_df["第一關金幣"] >= 60) & (game_df["第二關金幣"] >= 60)]
```

### ❌ 把新欄位放在右邊

```python
game_df["第一關金幣"] + game_df["第二關金幣"] = game_df["總金幣"]
```

**原因：** Python 要先計算右邊，再把結果放入左邊。

**✅ 修正：**

```python
game_df["總金幣"] = game_df["第一關金幣"] + game_df["第二關金幣"]
```

## 本課小結

1. `game_df[條件]` 可以保留符合條件的資料列。

3. 用 `資料表["新欄位"] = 計算結果` 可以加入新欄位。
