## 新概念

### 1. 一份最小模型報告的五項內容

1. **問題**：模型要回答甚麼？
2. **資料**：資料從哪裡來、有哪些欄位？
3. **方法**：使用甚麼模型和設定？
4. **測試結果**：在未見資料上表現如何？
5. **限制與下一步**：它沒有看見甚麼？還需要怎樣改善？

### 2. 資料使用要先考慮人

課堂專題宜使用公開、匿名或虛構資料。不要未經同意收集同學的個人資料；更不應讓模型自動替人作升學、紀律、健康或其他重大決定。

## 跟著做：例子 1——完整的鳶尾花分類小專題

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

# 1. 取得公開教學資料
iris = load_iris()

# 2. 分開訓練資料和未見過的測試資料
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target,
    test_size=0.25,
    random_state=12,
    stratify=iris.target
)

# 3. 訓練模型，再對測試資料預測
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# 4. 報告測試結果
print("測試準確率：", accuracy_score(y_test, y_pred))
```

### 預期輸出／結果

畫面會顯示約 `0.95` 的測試準確率。這代表模型在這次保留的測試資料上表現不錯，但不是保證它能辨認所有真實世界的花。

### 逐行解釋

這段程式由資料載入開始，包含切分、訓練、預測和評估；因此可以由第一行重新執行。

這也是專題程式的重要原則：不要只依賴上一個 Notebook cell 或手動記住的結果。

## 易錯位

### ❌ 專題只報告最高準確率

準確率不會說明資料來源、資料量、錯誤類型或限制。

**✅ 修正：** 用五項內容交代整個模型報告。

### ❌ 程式只能由中間 cell 開始執行

這樣別人難以重現你的結果，也難以找到錯誤。

**✅ 修正：** 把「取得資料 → 切分 → 訓練 → 測試」放在同一段完整流程。

### ❌ 使用敏感個人資料作公開展示

即使資料能用來訓練，也不代表可以收集、上傳或公開。先考慮同意、私隱和可能傷害。
