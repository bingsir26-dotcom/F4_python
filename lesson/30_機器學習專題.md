## 新概念

### 1. 專題的六項內容

1. 問題與預測目標；2. 資料來源和欄位；3. 特徵與標籤；4. 訓練／測試方法；5. 指標與圖表；6. 結論、限制和改善方向。

### 2. 保護私隱與避免不當用途

不要使用未獲同意的個人資料；不要讓模型自動替人作重要評價、升學、醫療或紀律決定。學習專題宜使用公開、匿名或虛構資料。

## 跟著做：例子 1——完整的鳶尾花分類流程

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(iris.data, iris.target, test_size=0.25, random_state=42)

model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print("測試準確率：", accuracy_score(y_test, y_pred))
```

### 預期輸出／結果

輸出測試準確率。它只代表這次資料分割下的表現；請同時記錄模型和設定。

### 逐行解釋

`load_iris()` 提供公開教學資料。程式完整包含取得資料、切分、訓練、預測和評估，因此可由第一行重新執行。

## 再試一次：例子 2——為一筆資料作可讀展示

```python
new_flower = [[5.1, 3.5, 1.4, 0.2]]
prediction = model.predict(new_flower)[0]
print("預測類別：", iris.target_names[prediction])
```

`target_names` 把數字類別轉成花名。展示時請說明這是模型預測，不是用來辨識真實世界所有花的保證。

## 易錯位

### ❌ 專題只報告最高準確率

應同時說明資料、測試方法、錯誤類型和限制；高分不能取代這些資訊。

### ❌ 使用敏感資料作公開展示

即使資料能訓練模型，也不代表可以收集、上傳或公開。先確認私隱、同意和使用目的。
