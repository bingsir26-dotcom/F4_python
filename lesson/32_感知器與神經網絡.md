## 開始前：想一想

若兩個特徵對判斷的重要性不同，模型是否應給它們相同影響？感知器會用可學習的權重調整各輸入的影響。

## 新概念

### 1. 感知器

感知器先計算「輸入 × 權重」的總和，再加上偏差，最後經過激活函數。權重和偏差不是人手猜好，而是由訓練逐步調整。

### 2. 神經網絡

多個感知器組成一層；加入隱藏層和非線性激活函數後，模型可學習較複雜的關係。層數增加不必然更好，仍要有足夠資料和評估。

## 跟著做：例子 1——建立一個線性層

```python
import torch
from torch import nn

layer = nn.Linear(in_features=2, out_features=1)
x = torch.tensor([[1.0, 2.0]])
y = layer(x)

print(x.shape)
print(y.shape)
```

### 預期輸出／結果

輸入形狀是 `[1, 2]`：1 筆資料、2 個特徵；輸出形狀是 `[1, 1]`。數值每次可能不同，因為權重一開始會隨機初始化。

### 逐行解釋

`nn.Linear(2, 1)` 代表由兩個輸入特徵計算一個輸出。此時尚未訓練，因此輸出沒有實際預測意義。

## 再試一次：例子 2——加入隱藏層和 ReLU

```python
model = nn.Sequential(
    nn.Linear(2, 4),
    nn.ReLU(),
    nn.Linear(4, 1)
)

print(model(x))
```

第一層把 2 個特徵轉成 4 個隱藏數值；`ReLU()` 加入非線性；最後一層產生 1 個輸出。結構變複雜後，更需要訓練和測試。

## 易錯位

### ❌ 把未訓練輸出當作預測

剛建立的網絡權重是隨機的；要經過資料、損失函數和優化器訓練才有意義。

### ❌ 輸入特徵數不符

`nn.Linear(2, 1)` 需要每筆資料有 2 個特徵；傳入 3 個數字會出現形狀錯誤。

### 挑戰題

## 本課小結

1. 感知器以權重和偏差把輸入轉成輸出。
2. `nn.Linear` 是 PyTorch 的基本線性層。
3. 神經網絡要訓練後才有可用的預測能力。
