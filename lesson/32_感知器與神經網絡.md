# 第 32 課：感知器與神經網絡——讓特徵影響一個判斷

> **本課主題：看懂一個感知器如何把多個數字特徵合成一個分數。**
>
> 神經網絡不是「自動懂答案」的黑盒。最基本的單元只是在做加權計算：不同輸入配上不同權重，再加上一個偏差值。訓練會在下一課學習怎樣找出這些數字。

## 今課可以做到甚麼？

- 用兩個特徵、兩個權重和一個偏差算出模型分數；
- 使用 `nn.Linear(2, 1)` 建立一個基本感知器；
- 說出剛建立、尚未訓練的模型為甚麼不能直接相信。

## 開始前：想一想

假設模型要根據圖片中兩個已量度的特徵，判斷它是否「較接近某一類水果」。兩個特徵未必有一樣影響：一項數值改變，可能比另一項更影響結果。

模型如何把多個數字合成一個可以用來比較的分數？

## 新概念

### 1. 感知器：把特徵乘上權重，再加起來

一個感知器會計算：

```text
分數 = 特徵 1 × 權重 1 + 特徵 2 × 權重 2 + 偏差
```

權重表示目前模型把哪個特徵放得較重；偏差讓分數不必一定由 0 開始。這些數字在真正模型中不是由人憑感覺決定，而是由資料訓練出來。

![兩個水果圖片特徵以權重和偏差算出一個模型分數](/images/lesson-32-perceptron-network.svg)

### 2. 神經網絡：把多個計算單元排成多層

多個感知器可放在同一層；再把一層的輸出交給下一層，就成為神經網絡。層數較多可以表達較複雜的關係，但也需要更多資料、訓練和測試，並不是越多越好。

## 跟著做：例子 1——親手計算一個感知器分數

```python
import torch

# 一筆資料有兩個已縮放到 0 至 1 附近的特徵
features = torch.tensor([[0.9, 0.8]])
weights = torch.tensor([[1.2, 0.7]])
bias = torch.tensor([-1.0])

score = features @ weights.T + bias
print("模型分數：", score.item())
```

### 預期輸出

```text
模型分數： 0.64...
```

### 逐行解釋

`features` 是一筆資料的兩個特徵。`weights` 的兩個數字分別配對兩個特徵；`@` 表示把對應數字相乘後加起來。

本例計算的是 `0.9 × 1.2 + 0.8 × 0.7 - 1.0`，結果約為 `0.64`。它只是模型內部的分數，未訓練前不代表真實世界的結論。

## 再試一次：例子 2——用 PyTorch 的 `nn.Linear`

**先執行例子 1**，再加入以下程式：

```python
from torch import nn

layer = nn.Linear(2, 1)

with torch.no_grad():
    layer.weight[:] = weights
    layer.bias[:] = bias

print("Linear 層的分數：", layer(features).item())
```

`nn.Linear(2, 1)` 表示「每筆有 2 個輸入特徵，產生 1 個輸出分數」。我們暫時把它的權重和偏差設定成例子 1 的數字，所以輸出會相同；真正訓練時，模型會自行調整這些數字。

## 易錯位

### ❌ 把模型分數直接當成事實或最終決定

分數只是目前計算結果。它是否有用，要看訓練資料、分類規則和未見資料的測試。

**✅ 修正：** 把輸出看成需要評估的模型結果，不用它自動作出影響人的重大決定。

### ❌ 把權重理解成道德價值或人的重要程度

這裡的權重只是此模型、此資料和此任務中的數值參數；它不應用來評價人的價值。

### ❌ 忘記 `nn.Linear(2, 1)` 的輸入數量

這一層要求每筆資料有兩個特徵。若傳入三個數字，程式會因形狀不符而報錯。

## 本課小結

1. 感知器以「特徵 × 權重」加上偏差，算出一個分數。
2. `nn.Linear(2, 1)` 是一個有兩個輸入、一次輸出一個數字的基本層。
3. 權重必須經訓練和測試才有意義；未訓練輸出不能直接相信。
