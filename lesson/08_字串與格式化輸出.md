# 第 8 課：字串、文字處理與格式化輸出

> **本課主題：讓程式讀懂使用者輸入的文字，並把結果清楚地顯示出來。**
>
> 由 `input()` 得到的資料通常是文字。學會處理字串後，你可以做出更自然的問答程式、成績報告和遊戲訊息。

## 今課可以做到甚麼？

完成這一課後，你可以：

- 製作會讀取名字，並顯示個人化歡迎訊息的小程式；
- 用 f-string 將文字、變數和計算結果整齊地放在同一句輸出中；
- 處理輸入前後多出的空格，讓程式更可靠。

## 開始前：想一想

如果使用者輸入自己的名字，程式如何顯示下面這句？

```text
你好，小美！你目前有 120 金幣。
```

想一想：`小美` 和 `120` 是不是每次都一樣？如果不是，我們怎樣把它們放進同一句文字？

## 新概念

### 1. 字串就是一段文字

放在引號內的內容是字串（`str`）：

```python
message = "歡迎來到 Python 世界！"
```

名字、班別、按下的指令、`input()` 的結果，通常都是字串。

![字串可以由固定文字和可改變的變數值組合成一段清楚訊息](/images/lesson-08-strings.svg)

### 2. 用 f-string 把資料放進句子

在字串前加上 `f`，再用大括號 `{}` 包住變數名稱，就能把變數的值放進文字中：

```python
name = "小美"
gold = 120
print(f"你好，{name}！你目前有 {gold} 金幣。")
```

大括號內也可以放簡單計算：

```python
score = 78
print(f"加 5 分後是 {score + 5} 分。")
```

### 3. `.strip()` 清除輸入兩邊的空格

有人輸入名字時，可能不小心在前面或後面加了空格。`.strip()` 會移除文字**開頭和結尾**的空格：

```python
name = input("你的名字：").strip()
```

它不會刪除名字中間的空格。

## 跟著做：例子 1——個人化歡迎卡

```python
name = input("你的名字：").strip()
class_name = input("你的班別：").strip()

print(f"你好，{name}！")
print(f"歡迎 {class_name} 的同學開始 Python 挑戰。")
```

### 預期輸出／結果

```text
你的名字：小美
你的班別：F4A
你好，小美！
歡迎 F4A 的同學開始 Python 挑戰。
```

### 逐行解釋

```python
name = input("你的名字：").strip()
```

`input()` 取得使用者輸入的文字；`.strip()` 移除兩邊不小心輸入的空格；結果放進 `name`。

```python
print(f"你好，{name}！")
```

`f` 表示這是一個可放入資料的字串。Python 會把 `{name}` 換成 `name` 變數目前保存的文字。

## 再試一次：例子 2——遊戲角色狀態

只加入兩個數字變數，便可做出更像遊戲的輸出：

```python
player_name = "小明"
hp = 85
gold = 120

print(f"角色：{player_name}")
print(f"生命值：{hp}/100")
print(f"金幣：{gold}")
```

### 預期輸出／結果

```text
角色：小明
生命值：85/100
金幣：120
```

比較一下：不用 f-string 時，要把文字和變數分開寫；f-string 讓整句話的樣子更接近最後顯示的結果。

## 易錯位

### ❌ 忘記在字串前加 `f`

```python
name = "小美"
print("你好，{name}！")
```

Python 會真的顯示 `{name}`，不會替換內容。

**✅ 改成這樣：**

```python
print(f"你好，{name}！")
```

### ❌ 把文字當成沒有引號的變數

```python
print(你好)
```

`你好` 沒有引號，Python 會以為它是一個變數名稱。

**✅ 改成這樣：**

```python
print("你好")
```

### ❌ 把數字運算寫進普通字串

```python
score = 78
print("加分後：score + 5")
```

這只是一段固定文字，Python 不會計算。

**✅ 改成這樣：**

```python
print(f"加分後：{score + 5}")
```

## 本課小結

1. 引號內的內容是字串；`input()` 的結果也是字串。
2. f-string 可將 `{變數}` 或 `{簡單計算}` 放進一段文字。
3. `.strip()` 可移除輸入開頭和結尾多出的空格。
