## 開始前：想一想

如果你要教一個完全不懂人類語言的機械人完成這件事，你會怎樣寫指令？

```text
把 80 和 90 加起來，然後顯示結果。
```

人看到這句話大概會明白，但電腦需要更清楚的步驟。它不會自行補上你沒有寫出的意思，只會依照程式碼的先後次序執行。

### 先猜一猜

下面的三行程式，會以甚麼次序顯示內容？如果把第一行和第三行交換，輸出會不會改變？先猜，再執行驗證。

```python
print("先準備 80")
print("再準備 90")
print(80 + 90)
```

你應該會看見：

```text
先準備 80
再準備 90
170
```

這就是 Python 程式最基本的閱讀方式：**由上到下，一行一行執行。**

## 新概念

### 1. `print()`：把內容顯示出來

`print()` 會把括號內的文字、數字或計算結果顯示在輸出區。

```python
print("你好，Python！")
print(10)
print(3 + 4)
```

![程式碼經 Python 執行後在輸出區顯示結果](/images/print-flow.svg)

### 2. 文字和數字不一樣

看起來都是「10」，不代表 Python 把它們當成同一種資料。

```python
print("10" + "5")
print(10 + 5)
```

輸出是：

```text
105
15
```

- `"10"` 和 `"5"` 有引號，是文字；文字的 `+` 會把兩段內容接起來，所以得到 `105`。
- `10` 和 `5` 沒有引號，是數字；數字的 `+` 是加法，所以得到 `15`。

這件事很重要：顯示「歡迎 Alex」時，你需要文字；計算分數、金幣或平均分時，你需要數字。Python 必須知道你現在要它「接文字」還是「做計算」。

### 3. 變數：替資料貼上標籤

變數（variable）是用來保存資料的名字。把資料放進變數後，之後只要寫出這個名字，就能使用那份資料。

```python
score = 80
print(score)
```

這段程式的意思是：

1. 建立一個叫 `score` 的變數；
2. 把數字 `80` 放入 `score`；
3. 使用 `print(score)` 顯示變數中的資料。

![多個變數盒子，其中 score 保存 80](/images/variable-boxes-score.svg)

**看圖說一說：** `score` 是資料的名字，還是資料本身？如果把 `80` 改成 `95`，哪一部分會改變？

### 4. `=` 在這裡是「放入」

初學者常把 `=` 當成數學中的「兩邊相等」。在 Python 建立或更新變數時，可以先把它理解成「把右邊的資料放入左邊的名稱」。

```python
player_name = "Alex"
hp = 100
```

可以讀成：

```text
把 "Alex" 放入 player_name
把 100 放入 hp
```

### 5. 變數可以更新

在遊戲中，角色受到攻擊後，生命值會減少；撿到寶箱後，金幣會增加。

```python
hp = 100
hp = hp - 20
gold = 30
gold = gold + 10

print(hp)
print(gold)
```

輸出是：

```text
80
40
```

以 `hp = hp - 20` 為例：

1. 先取出 `hp` 原本的數值 `100`；
2. 計算 `100 - 20`，得到 `80`；
3. 把新的 `80` 放回 `hp`。

右邊會先計算，結果才放回左邊的變數。

### 6. 變數命名規則

變數名稱是給人和 Python 看的標籤。清楚的名稱能讓你幾星期後回看程式，仍然知道資料代表甚麼。

```python
student_name = "Amy"
math_score = 88
```

基本規則：

- 不可以用數字開頭：`1score` ❌
- 不可以包含空格：`student name` ❌
- 不可以使用運算符號：`score-total` ❌
- 英文字母大小寫不同：`score` 和 `Score` 是兩個名稱。

兩個以上的英文單字，常見有兩種寫法：

```python
player_hp = 100   # snake_case：單字之間用底線，Python 最常見
playerHp = 100    # camelCase（駱駝峰命名法）：新單字首字母大寫
```

**駱駝峰命名法**的名字像駱駝的背一樣有起伏：第一個字小寫，後面每個新字的第一個字母大寫，例如 `playerName`、`totalScore`。

兩種寫法 Python 都能理解；但為了容易閱讀，**本課程的 Python 程式一律優先使用 `snake_case`**。不要在同一個程式中混用兩種風格。

## 跟著做：例子 1——我的第一個 Python 程式

請把以下程式逐行輸入或貼到 Jupyter 的 Code cell，然後執行：

```python
print("大家好，我正在學 Python！")
print("今年我會寫出自己的小程式。")
print(20 + 26)
```

### 預期輸出

```text
大家好，我正在學 Python！
今年我會寫出自己的小程式。
46
```

### 逐行解釋

```python
print("大家好，我正在學 Python！")
```

顯示一段文字。因為內容是文字，所以要放在引號內。

```python
print("今年我會寫出自己的小程式。")
```

這是第二個輸出指令。Python 會按照由上到下的次序執行，所以它在第一行之後顯示這一句。

```python
print(20 + 26)
```

這一行沒有引號，所以 Python 會先計算 `20 + 26`，再把結果 `46` 顯示出來。

### 小檢查

如果把最後一行改成以下寫法，輸出會是甚麼？

```python
print("20 + 26")
```

答案不是 `46`，而是顯示文字：

```text
20 + 26
```

## 再試一次：例子 2——用變數保存遊戲資料

這次把直接寫在 `print()` 裡的資料，改為先保存到變數：

```python
player_name = "Alex"
hp = 100
gold = 30

print(player_name)
print(hp)
print(gold)
```

### 預期輸出

```text
Alex
100
30
```

### 逐行解釋

```python
player_name = "Alex"
```

建立 `player_name`，並把文字 `"Alex"` 放進去。

```python
hp = 100
gold = 30
```

建立兩個變數，分別保存生命值和遊戲金幣。

```python
print(hp)
print(gold)
```

寫出變數名稱而不加引號，Python 就會取出變數裡的資料並顯示。

### 再改一個地方

角色撿到一個裝有 `10` 金幣的寶箱。只在 `print(gold)` 前加入一行：

```python
gold = gold + 10
```

其餘程式不變，最後顯示的金幣數量會由 `30` 變成多少？

這就是變數的好處：資料改變時，只要更新變數；所有使用它的地方都會取得最新資料。

## 易錯位

### ❌ 忘記文字的引號

**錯誤寫法**

```python
print(Hello)
```

Python 會把 `Hello` 當成變數名稱，但我們沒有先建立它。

**✅ 改成這樣**

```python
print("Hello")
```

### ❌ 括號或引號沒有成對

**錯誤寫法**

```python
print("Hello"
```

**✅ 改成這樣**

```python
print("Hello")
```

每一個左括號 `(` 都要有右括號 `)`；每一個開頭引號也要有結尾引號。

### ❌ 把變數名稱放進引號

**錯誤寫法**

```python
score = 80
print("score")
```

輸出會是文字：

```text
score
```

**✅ 改成這樣**

```python
print(score)
```

不加引號時，Python 才會取出 `score` 裡的 `80`。

### ❌ 變數名稱前後不一致

**錯誤寫法**

```python
student_name = "Amy"
print(studentName)
```

`student_name` 和 `studentName` 是不同名稱。選好寫法後，要在整個程式中使用完全相同的拼法。
