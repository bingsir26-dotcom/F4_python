## 新概念

### 1. `print()`：把內容顯示出來

`print()` 是 Python 中常用的輸出指令。它可以把文字、數字或計算結果顯示在畫面上。

```python
print("你好，Python！")
print(10)
print(3 + 4)
```

生活比喻：`print()` 就像拿著擴音器把內容讀出來。程式內的資料可能暫時放在電腦中，但我們使用 `print()` 才能看見它。

> 建議圖片：`程式碼 → Python 執行 → 螢幕輸出` 的三格流程圖。

### 2. 文字和數字不一樣

```python
print("10")
print(10)
```

兩行看起來都會顯示 `10`，但它們的資料性質不同：

- `"10"` 是文字；
- `10` 是數字。

引號是重要提示：放在引號內的內容，Python 會先當作文字處理。

### 3. 變數：替資料貼上標籤

變數（variable）可以想像成一個貼了標籤的盒子，用來保存資料。

```python
score = 80
print(score)
```

這段程式的意思是：

1. 建立一個叫 `score` 的變數；
2. 把數字 `80` 放入變數；
3. 使用 `print(score)` 顯示變數中的資料。

> [待加入圖片]
> 建議圖片：一個寫著 `score` 的盒子，盒內有 `80`。

### 4. `=` 在這裡是「放入」

初學者常常把 `=` 當成數學中的「兩邊相等」。在 Python 變數中，可以先把它理解為「把右邊的資料放入左邊的名稱」。

```python
name = "Amy"
age = 15
```

可以讀成：

```text
把 "Amy" 放入 name
把 15 放入 age
```

### 5. 變數可以更新

```python
score = 80
score = score + 5
print(score)
```

執行後會顯示：

```text
85
```

第二行可以拆開來理解：

1. 先取出 `score` 原本的 `80`；
2. 計算 `80 + 5`，得到 `85`；
3. 把新的 `85` 放回 `score`。

這種寫法日後會用來計算總分、累積次數和更新遊戲分數。

### 6. 變數命名規則

變數名稱是給人和 Python 看的標籤。好的名稱可以令程式更容易閱讀。

```python
student_name = "Amy"
math_score = 88
```

基本規則：

- 不可以用數字開頭：`1score` ❌
- 不可以包含空格：`student name` ❌
- 不可以使用運算符號：`score-total` ❌
- 英文字母大小寫不同：`score` 和 `Score` 是兩個名稱；
- 建議使用有意義的英文名稱，單字之間用底線分隔。

以下名稱雖然可能可以執行，但不容易明白：

```python
x = 88
n = "Amy"
```

較好的寫法是：

```python
math_score = 88
student_name = "Amy"
```

## 跟著做：例子 1——我的第一個 Python 程式

請把以下程式逐行輸入或貼到 Jupyter 的 Code cell，然後執行：

```python
print("大家好，我正在學 Python！")
print("Python 可以幫我處理資料。")
print(20 + 26)
```

### 預期輸出

```text
大家好，我正在學 Python！
Python 可以幫我處理資料。
46
```

### 逐行解釋

```python
print("大家好，我正在學 Python！")
```

顯示一段文字。因為內容是文字，所以要放在引號內。

```python
print("Python 可以幫我處理資料。")
```

這是第二個輸出指令。Python 會按照由上到下的次序執行。

```python
print(20 + 26)
```

這一行沒有引號，所以 Python 會先計算 `20 + 26`，再把結果 `46` 顯示出來。

### 小檢查

如果把最後一行改成以下寫法，輸出會是甚麼？

```python
print("20 + 26")
```

答案不是 `46`，而是顯示文字：

```text
20 + 26
```

## 再試一次：例子 2——用變數保存資料

這次只把直接寫在 `print()` 裡的資料改為變數：

```python
student_name = "Amy"
math_score = 80
english_score = 90

print(student_name)
print(math_score)
print(english_score)
print(math_score + english_score)
```

### 預期輸出

```text
Amy
80
90
170
```

### 逐行解釋

```python
student_name = "Amy"
```

建立 `student_name`，並把文字 `"Amy"` 放進去。

```python
math_score = 80
english_score = 90
```

建立兩個變數，分別保存數學和英文分數。

```python
print(math_score + english_score)
```

取出兩個變數中的數字，先相加，再顯示結果。

### 再改一個地方

只把數學分數由 `80` 改成 `95`：

```python
math_score = 95
```

其餘程式不變，最後的總分會如何改變？

這就是使用變數的好處：資料改變時，不需要在很多地方重寫同一個數字。

## 易錯位

### 錯誤一：忘記文字的引號

錯誤：

```python
print(Hello)
```

Python 會把 `Hello` 當成一個變數名稱，但我們並沒有先建立它。

修正：

```python
print("Hello")
```

### 錯誤二：括號或引號沒有成對

錯誤：

```python
print("Hello"
```

修正：

```python
print("Hello")
```

### 錯誤三：把變數名稱放進引號

```python
score = 80
print("score")
```

輸出會是：

```text
score
```

如果想顯示變數內的 `80`，應寫成：

```python
print(score)
```

### 錯誤四：變數名稱前後不一致

```python
student_name = "Amy"
print(studentName)
```

`student_name` 和 `studentName` 是不同名稱。修正方法是前後使用完全相同的拼法。


### 挑戰題：計算測驗後的新平均分

已知第一次測驗的平均分是 `72`，第二次測驗得到 `86`。如果只計算兩次測驗的平均分，請：

1. 用變數保存兩次分數；
2. 計算平均分；
3. 顯示結果。

提示：

```python
average = (test_1 + test_2) / 2
```

## 本課小結

1. `print()` 可以把文字、數字或計算結果顯示出來。
2. 引號內的內容是文字；沒有引號的數字可以進行數學運算。
3. 變數是保存資料的名稱；`=` 可以理解為把右邊的資料放入左邊的變數。
