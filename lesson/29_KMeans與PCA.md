# 第 29 課：K-Means——在未標籤資料中找群組

> **本課主題：當資料沒有預先答案時，依相似程度把它們分成幾個群組。**
>
> 前面的分類模型需要已知答案，例如「長袖／短袖」。分群則不先給答案；它只根據資料之間的相近程度，嘗試找出可能的群組。

## 今課可以做到甚麼？

- 分辨「分類」和「分群」的差別；
- 用 K-Means 把兩個特徵的資料分成兩群；
- 畫出群組和中心，檢查分群是否看起來合理。

## 開始前：想一想

假設你有六首歌曲的「節奏快慢」和「音量」資料，但沒有任何曲風標籤。你只想看看它們會不會自然分成兩組。

這時候沒有正確類別可交給模型；我們只是在探索資料中的相似模式。

## 新概念

### 1. 分類和分群的分別

- **分類**：訓練資料已有答案，例如「戶外／室內」；
- **分群**：資料沒有預先答案，只按相似程度分組。

### 2. K-Means 的基本想法

K-Means 先設定想分成幾群，然後找出每群的中心，讓同一群的資料盡量靠近該中心。

![六筆沒有標籤的資料被 K-Means 分成兩群，並標示每群中心](/images/lesson-29-kmeans-pca.svg)

`n_clusters=2` 不是自然定律，而是我們在這次分析中選擇找兩群。群組編號 0、1 只是名稱，不代表高低或好壞。

> **延伸一提：** PCA 是日後把很多特徵壓成較少觀察軸的工具。這一課先不使用它，先把「沒有答案也可以探索資料」的 K-Means 概念學清楚。

## 跟著做：例子 1——把兩個特徵分成兩群

```python
from sklearn.cluster import KMeans

# 每筆資料有兩個數值特徵，例如歌曲的節奏分數和音量分數
X = [[1, 1], [1.5, 2], [2, 1], [8, 8], [8.5, 9], [9, 8]]

kmeans = KMeans(n_clusters=2, random_state=0, n_init=10)
kmeans.fit(X)

print("每筆資料的群組：", kmeans.labels_)
print("群組中心：", kmeans.cluster_centers_)
```

### 預期輸出／結果

六筆資料會被分成兩組。你可能看到前面三筆同屬一組、後面三筆同屬另一組；群組 0 和 1 的次序可能與你想像相反，但分組關係相同。

### 逐行解釋

`X` 內每個小 List 有兩個數字。`n_clusters=2` 告訴 K-Means：這次嘗試找兩個群組。

`kmeans.labels_` 保存每筆資料分到的群組編號；`kmeans.cluster_centers_` 顯示兩群各自的中心位置。

## 再試一次：例子 2——把群組畫出來

**先執行例子 1**，再執行以下程式：

```python
import matplotlib.pyplot as plt

x_values = [row[0] for row in X]
y_values = [row[1] for row in X]

plt.scatter(x_values, y_values, c=kmeans.labels_)
plt.scatter(
    kmeans.cluster_centers_[:, 0],
    kmeans.cluster_centers_[:, 1],
    c="red", marker="X", s=180
)
plt.xlabel("特徵 1")
plt.ylabel("特徵 2")
plt.show()
```

不同顏色的點代表不同群組；紅色 X 是每群中心。畫圖可幫助我們檢查這兩群是否真的分得開。

## 易錯位

### ❌ 以為群組編號是排名

群組 1 不代表比群組 0 好；它只是程式使用的名稱。

### ❌ 以為分群已經找到真正原因

K-Means 只根據你提供的數字分組。群組是否有意義，仍要由問題背景和人作解釋。

### ❌ 任意選擇群數後當成唯一答案

試著改成 3 群並看圖；不同群數可能都有不同用途。

## 本課小結

1. 分群沒有預先提供每筆資料的正確類別。
