## 新概念

### 1. K-Means 分群

K-Means 要求先指定 `n_clusters`，然後反覆調整每個群的中心，讓同群資料較接近中心。它產生的是群組編號，不一定有固定人類意義。

### 2. PCA 降維

PCA 把多個特徵轉換為較少的新軸，保留較多變化方向。它常用於視覺化與前處理，不是把資料「變得更真實」。

![非監督學習的核心概念：資料點、群組、中心、降維](/images/lesson-29-kmeans-pca.svg)

## 跟著做：例子 1——把兩個特徵分成兩群

```python
from sklearn.cluster import KMeans

X = [[1, 1], [1.5, 2], [2, 1], [8, 8], [8.5, 9], [9, 8]]

kmeans = KMeans(n_clusters=2, random_state=0, n_init=10)
kmeans.fit(X)

print(kmeans.labels_)
print(kmeans.cluster_centers_)
```

### 預期輸出／結果

`labels_` 顯示每筆資料所屬群組的編號；`cluster_centers_` 顯示各群中心位置。群組 0、1 的名字可互換，不代表高低。

### 逐行解釋

這裡每筆資料有兩個數值特徵。`n_clusters=2` 是我們指定想找兩群；不同資料或不同群數可得到不同結果。

## 再試一次：例子 2——把分群結果畫成散點圖

```python
import matplotlib.pyplot as plt

plt.scatter([row[0] for row in X], [row[1] for row in X], c=kmeans.labels_)
plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1], c="red", marker="X", s=180)
plt.show()
```

點的顏色由群組編號決定；紅色 X 是群中心。圖表幫助檢查資料是否真的有明顯可分的群組。

## 易錯位

### ❌ 把群組編號解讀為排名

群組 1 不代表比群組 0 好；編號只是程式給的名稱。

### ❌ 任意選擇群數後當成唯一答案

群數是分析選擇。應結合問題背景、圖表與不同 `n_clusters` 的結果判斷。
