## 新概念

### 本課起始 cell：先執行一次

若剛開啟新的 Notebook／Colab，先執行這一格。後面的清洗例子都會使用同一張 `game_df`；這張表故意放入一個缺失第二關金幣和兩種紅隊寫法。

```python
import pandas as pd

game_data = {
    "玩家": ["Nova", "Rex", "Mira", "Kai"],
    "隊伍": ["紅隊", "紅 隊", "藍隊", "藍隊"],
    "第一關金幣": [78, 65, 91, 72],
    "第二關金幣": [82, None, 88, 70]
}

game_df = pd.DataFrame(game_data)
```

### 1. 缺失值 `NaN`

pandas 用 `NaN` 表示缺失數值資料。它不是 0，也不代表角色一定沒有獲得金幣；它只表示「這個位置沒有可用數值」。

> **清洗不是修改結果：** 目標是修正明顯的輸入格式或處理缺漏，同時保留原始資料和處理原因；不能為了令分析結果更好看而隨意改數字。

```python
game_df.isna()
```

會逐格顯示 True／False：`True` 代表該格缺失。

```python
game_df.isna().sum()
```

會統計每一欄有多少個缺失值。

### 2. 刪除和補上是不同決定

```python
game_df.dropna()
```

刪除含有缺失值的資料列。適合資料很少、而且缺失列不能使用的情況。

```python
game_df["第二關金幣"] = game_df["第二關金幣"].fillna(game_df["第二關金幣"].mean())
```

用第二關金幣欄的平均值補上缺失。適合只是需要做整體統計、又不想因一個空白失去整列資料的情況。

### 3. 不同寫法也會令分析錯誤

`紅隊`、`紅 隊`、`紅隊 ` 人看起來差不多，但 Python 視為不同文字。分組前要先統一寫法。注意：`replace("紅 隊", "紅隊")` 只會處理完全相同的 `"紅 隊"`；多出的空格仍要另外處理。

## 跟著做：例子 1——找出並補上缺失第二關金幣

```python
import pandas as pd

game_data = {
    "玩家": ["Nova", "Rex", "Mira", "Kai"],
    "隊伍": ["紅隊", "紅 隊", "藍隊", "藍隊"],
    "第一關金幣": [78, 65, 91, 72],
    "第二關金幣": [82, None, 88, 70]
}

game_df = pd.DataFrame(game_data)
print(game_df.isna().sum())

game_df["第二關金幣"] = game_df["第二關金幣"].fillna(game_df["第二關金幣"].mean())
print(game_df)
```

### 預期輸出

```text
玩家        0
隊伍        0
第一關金幣    0
第二關金幣    1
dtype: int64

     玩家   隊伍  第一關金幣      第二關金幣
0  Nova   紅隊        78  82.000000
1   Rex  紅 隊        65  80.000000
2  Mira   藍隊        91  88.000000
3   Kai   藍隊        72  70.000000
```

第二關金幣欄已有 82、88、70，平均是 80，所以 Rex 的缺失值被補成 80。

### 逐行解釋

```python
"第二關金幣": [82, None, 88, 70]
```

`None` 表示這筆資料暫時缺失；pandas 顯示時會把它視為缺失值。

```python
print(game_df.isna().sum())
```

先數一數每一欄缺失多少資料。這是清洗前的重要檢查。

```python
game_df["第二關金幣"] = game_df["第二關金幣"].fillna(game_df["第二關金幣"].mean())
```

計算第二關金幣平均值，並把缺失位置補上該平均值；結果放回第二關金幣欄。

## 易錯位

### ❌ 未檢查便直接刪除資料

```python
game_df = game_df.dropna()
```

**問題：** 這會刪掉整列資料。若缺少的只是第二關金幣，而玩家和第一關金幣仍有用，可能太可惜。

**✅ 先做：**

```python
print(game_df.isna().sum())
```

先知道缺失在哪一欄、共有多少筆，再決定。

### ❌ 把 `NaN` 當成 0

```python
game_df["第二關金幣"] = game_df["第二關金幣"].fillna(0)
```

**問題：** 0 是真正的金幣數量；空白未必代表 0。除非資料規則明確說明，否則不可隨便補 0。

### ❌ 忘記把處理結果保存回去

```python
game_df["第二關金幣"].fillna(game_df["第二關金幣"].mean())
```

**問題：** 程式只產生了一份處理後結果，原表沒有改變。

**✅ 修正：**

```python
game_df["第二關金幣"] = game_df["第二關金幣"].fillna(game_df["第二關金幣"].mean())
```
