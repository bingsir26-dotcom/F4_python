>
> 真實資料常有空白、不同寫法或不合理值。這一課不只是背指令，而是學會先判斷「這份資料可以相信嗎？」

## 今課可以做到甚麼？

- 找出資料表中的缺失值；
- 根據資料意義選擇刪除或補上資料；
- 修正同一類資料的不同寫法，令後續分析更可靠。

## 開始前：想一想

假設某位學生的英文成績沒有輸入：

| 姓名 | 數學 | 英文 |
|---|---:|---:|
| Alex | 78 | 82 |
| Chris | 65 | 空白 |
| May | 91 | 88 |

如果直接把空白當成 `0` 分，公平嗎？如果直接刪除 Chris，又會否失去有用資料？

### 先猜一猜

下列哪一種做法一定正確？

1. 所有空白都刪除。
2. 所有空白都補 0。
3. 先知道空白代表甚麼，再決定。

答案是 **3**。資料清洗沒有一個永遠正確的按鈕；程式可以幫你處理，但你要先理解資料。

## 新概念

### 1. 缺失值 `NaN`

pandas 用 `NaN` 表示缺失數值資料。它不是 0，也不代表學生一定沒有作答；它只表示「這個位置沒有可用數值」。

```python
scores_df.isna()
```

會逐格顯示 True／False：`True` 代表該格缺失。

```python
scores_df.isna().sum()
```

會統計每一欄有多少個缺失值。

### 2. 刪除和補上是不同決定

```python
scores_df.dropna()
```

刪除含有缺失值的資料列。適合資料很少、而且缺失列不能使用的情況。

```python
scores_df["英文"] = scores_df["英文"].fillna(scores_df["英文"].mean())
```

用英文欄的平均值補上缺失。適合只是需要做整體統計、又不想因一個空白失去整列資料的情況。

### 3. 不同寫法也會令分析錯誤

`F4A`、`F4 A`、`f4a` 人看起來差不多，但 Python 視為三種不同文字。分組前要先統一寫法。注意：`replace("F4 A", "F4A")` 只會處理完全相同的 `"F4 A"`；`"f4a"` 仍要另外指定。

## 跟著做：例子 1——找出並補上缺失英文成績

```python
import pandas as pd

student_data = {
    "姓名": ["Alex", "Chris", "May", "Sam"],
    "班別": ["F4A", "F4 A", "F4B", "F4B"],
    "數學": [78, 65, 91, 72],
    "英文": [82, None, 88, 70]
}

scores_df = pd.DataFrame(student_data)
print(scores_df.isna().sum())

scores_df["英文"] = scores_df["英文"].fillna(scores_df["英文"].mean())
print(scores_df)
```

### 預期輸出

```text
姓名    0
班別    0
數學    0
英文    1
dtype: int64

     姓名   班別  數學         英文
0  Alex  F4A  78  82.000000
1 Chris  F4 A  65  80.000000
2   May  F4B  91  88.000000
3   Sam  F4B  72  70.000000
```

英文欄已有 82、88、70，平均是 80，所以 Chris 的缺失值被補成 80。

### 逐行解釋

```python
"英文": [82, None, 88, 70]
```

`None` 表示這筆資料暫時缺失；pandas 顯示時會把它視為缺失值。

```python
print(scores_df.isna().sum())
```

先數一數每一欄缺失多少資料。這是清洗前的重要檢查。

```python
scores_df["英文"] = scores_df["英文"].fillna(scores_df["英文"].mean())
```

計算英文平均值，並把英文欄的缺失位置補上該平均值；結果放回英文欄。

## 易錯位

### ❌ 未檢查便直接刪除資料

```python
scores_df = scores_df.dropna()
```

**問題：** 這會刪掉整列資料。若缺少的只是英文，而姓名和數學仍有用，可能太可惜。

**✅ 先做：**

```python
print(scores_df.isna().sum())
```

先知道缺失在哪一欄、共有多少筆，再決定。

### ❌ 把 `NaN` 當成 0

```python
scores_df["英文"] = scores_df["英文"].fillna(0)
```

**問題：** 0 是真正的分數；空白未必代表 0 分。除非資料規則明確說明，否則不可隨便補 0。

### ❌ 忘記把處理結果保存回去

```python
scores_df["英文"].fillna(scores_df["英文"].mean())
```

**問題：** 程式只產生了一份處理後結果，原表沒有改變。

**✅ 修正：**

```python
scores_df["英文"] = scores_df["英文"].fillna(scores_df["英文"].mean())
```
