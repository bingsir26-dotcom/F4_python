## 這不是一套「只背語法」的課

Python 的語法是工具，不是終點。這門課會先讓你寫出可以立即看到結果的小程式，之後再把相同的思考方式，帶到資料整理、計算和圖表之中。

::: tip 上課時：切換成投影模式
右上角按 **「上課投影」**，便會暫時收起上欄、左側課程目錄和右側本課目錄，讓內容佔滿畫面。再次按 **「顯示導覽」** 或鍵盤按 `Esc`，便可回到一般閱讀模式。
:::

## 你會由小程式走到真實任務

| 學習階段 | 你會做甚麼 | 可以解決的問題 |
| --- | --- | --- |
| Python 基礎 | 輸出、變數、輸入、判斷、列表、迴圈 | 讓電腦按步驟計算、記錄和重複工作 |
| 資料分析 | 資料表、清洗、統計、篩選 | 從雜亂資料找出答案，例如平均值、排名或不同組別的差異 |
| 資料視覺化 | 用圖表表達結果 | 把調查或紀錄變成容易理解的故事 |
| 延伸方向 | 認識機器學習的分類概念 | 明白模型如何由例子學習，以及為何要小心資料偏見和錯誤 |

## 今天就可以開始

1. **第 0 課**：先看看 Python 和人工智能、資料分析有甚麼關係。
2. **第 1 課**：寫第一行程式，學會讓電腦顯示資料和保存資料。
3. 之後每一課都會有「想一想 → 跟著做 → 你來做」，不是只看答案。

> 目前課程已包含 Python 基礎和資料分析單元；「機器學習」會先作為你知道 Python 可延伸到哪裡的介紹方向，日後可以再加入獨立專題。
