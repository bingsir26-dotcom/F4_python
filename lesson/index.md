## 怎樣使用這個課程網站？

### 上課時

1. 用左側目錄打開當天課題。
2. 先完成「開始前：想一想」，不要急著看答案。
3. 跟著輸入程式、執行、觀察輸出。
4. 完成「你來做」的基礎題，再按自己的進度挑戰。
5. 最後用「離堂前 3 分鐘」檢查自己是否掌握。

### 課後時

- 回看範例和易錯位；
- 把程式改成自己的題材；
- 記錄一個仍然不明白的問題；
- 不要只複製答案，要先預測程式會做甚麼。

::: tip 開始之前
如果你從未寫過程式，請先看「第 0 課：為甚麼學 Python？」；它不考語法，只帶你看看這門課會通往哪裡。
:::

## 課程地圖

```text
第 0 課  為甚麼學 Python？
   ↓
第 1–8 課  Python 基礎：輸出、變數、輸入、判斷、列表、迴圈
   ↓
第 9 課  基礎測驗與綜合應用
   ↓
第 10–15 課  資料表、清洗、統計、圖表與資料分析
```

> 教材正在逐課重寫與補強中。第 0 課和第 1 課已採用新的「情境 → 概念 → 範例 → 練習 → 小結」編寫方式。
