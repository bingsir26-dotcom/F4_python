## 新概念

### 1. 資料有不同類型

Python 會記住資料是甚麼類型。初學時最常用的是以下四種：

```python
hp = 100              # int：整數
price = 19.9          # float：小數
player_name = "Alex"  # str：文字
is_ready = True       # bool：真或假
```

- `int`：沒有小數點的數字，例如人數、分數、生命值；
- `float`：有小數點的數字，例如價錢、平均分；
- `str`：文字（string），要放在引號內；
- `bool`：只有 `True` 或 `False`，用來表示「是／否」。

![Python 常見資料類型：整數、小數、文字、布林值](/images/lesson-02-data-types.svg)

想查看資料類型，可以使用 `type()`：

```python
score = 80
print(type(score))
```

輸出會顯示：

```text
<class 'int'>
```

### 2. 用運算子計算

`+`、`-`、`*`、`/` 是 Python 的計算工具。

```python
coins = 50
price = 18

print(coins - price)
print(6 * 8)
print(90 / 2)
```

輸出是：

```text
32
48
45.0
```

注意：除法 `/` 的答案通常會是小數，所以 `90 / 2` 顯示為 `45.0`。

### 3. 整除和餘數：分組與判斷奇偶

有些問題不是要小數答案，而是要知道「可以完整分成幾組」或「有沒有剩下」。

```python
students = 17
print(students // 4)  # 可完整分成幾組
print(students % 4)   # 剩下多少人

number = 13
print(number % 2)
```

輸出是：

```text
4
1
1
```

- `//` 是**整除**：`17 // 4` 只保留完整的 4 組；
- `%` 是**餘數**：`17 % 4` 是分組後剩下的 1 人；
- 一個數除以 2 的餘數是 `0`，就是偶數；餘數是 `1`，就是奇數。

計算式較長時，可用括號清楚表達先後次序：

```python
average = (78 + 65 + 91) / 3
```

### 4. 用比較運算子問問題

比較運算子會產生 `True`（真）或 `False`（假）。

```python
score = 78

print(score >= 60)
print(score == 100)
print(score != 0)
```

輸出是：

```text
True
False
True
```

常用比較方法：

| 寫法 | 意思 | 例子 |
| --- | --- | --- |
| `>` | 大於 | `score > 60` |
| `>=` | 大於或等於 | `score >= 60` |
| `<` | 小於 | `hp < 20` |
| `<=` | 小於或等於 | `age <= 18` |
| `==` | 是否相同 | `answer == 7` |
| `!=` | 是否不同 | `name != "Alex"` |

### 5. 同時檢查兩個條件

有時一個答案要同時符合兩個規則。`and` 表示「兩邊都要成立」；`or` 表示「其中一邊成立就可以」。

```python
score = 78
attendance = 90

print(score >= 60 and attendance >= 80)
print(score >= 90 or attendance >= 95)
```

輸出是：

```text
True
False
```

現在只要先看懂這種寫法；下一課用 `if` 時，才會真正用它決定程式要做甚麼。

### 6. 文字數字要先轉換

有時資料看起來像數字，其實仍是文字。

```python
print("5" + "3")
print(5 + 3)
```

輸出是：

```text
53
8
```

如果你拿到文字形式的數字，例如 `"5"`，想用來計算，可以用 `int()` 轉成整數：

```python
bonus = int("5")
print(bonus + 3)
```

## 跟著做：例子 1——計算遊戲購物後的金幣

```python
coins = 50
sword_price = 18
shield_price = 12

remaining_coins = coins - sword_price - shield_price
print(remaining_coins)
```

### 預期輸出

```text
20
```

### 逐行解釋

```python
coins = 50
sword_price = 18
shield_price = 12
```

先用三個變數保存原有金幣和兩件物品的價錢。

```python
remaining_coins = coins - sword_price - shield_price
```

Python 先取出三個變數中的數字，完成減法，再把答案保存到 `remaining_coins`。

```python
print(remaining_coins)
```

顯示購物後剩下的金幣。

## 再試一次：例子 2——金幣夠不夠？

只加入一行，讓 Python 回答「金幣是否足夠購買兩件物品」：

```python
can_buy = coins >= sword_price + shield_price
print(can_buy)
```

預期輸出：

```text
True
```

`coins >= sword_price + shield_price` 先計算右邊總價 `30`，再比較 `50` 是否大於或等於 `30`。

## 易錯位

### ❌ 把文字和數字直接相加

**錯誤寫法**

```python
print("5" + 3)
```

`"5"` 是文字，`3` 是數字；Python 不知道應該把它們接起來還是相加。

**✅ 改成這樣**

```python
print(int("5") + 3)
```

### ❌ 用一個 `=` 進行比較

**錯誤寫法**

```python
print(score = 60)
```

`=` 是把資料放入變數；比較兩個資料是否相同，要使用兩個等號。

**✅ 改成這樣**

```python
print(score == 60)
```

### ❌ 忘記文字要加引號

**錯誤寫法**

```python
player_name = Alex
```

**✅ 改成這樣**

```python
player_name = "Alex"
```
