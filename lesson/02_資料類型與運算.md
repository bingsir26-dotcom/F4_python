# 第 2 課：資料類型與運算

## 2.1 資料類型

```python
a = 10          # int
b = 3.14        # float
name = "Tom"    # str
ok = True       # bool
```

👉 查看類型：

```python
print(type(a))
```

## 2.2 比較運算子

```python
print(5 > 3)    # True
print(5 == 5)   # True
print(4 != 4)   # False
```

## 2.3 型別很重要（超重要）

```python
print("5" + "3")   # 53
print(5 + 3)       # 8
print("5" + 3)     # ❌ 錯誤
```

👉 解決方法：

```python
print(int("5") + 3)
```
