## 新概念

### 1. 三份資料的角色

訓練集學習參數；驗證集協助選設定和觀察過擬合；測試集留到最後作較公正的總結。

### 2. 常用技巧

- **標準化**：令不同尺度特徵較容易一起學習。
- **Adam**：常用優化器，會自動調整更新方式。
- **Dropout**：訓練時暫時關閉部分連線，減少過度依賴。
- **Early stopping**：驗證表現不再改善時停止。

## 跟著做：例子 1——以 Adam 取代 SGD

```python
import torch
from torch import nn

x = torch.tensor([[1.0], [2.0], [3.0], [4.0]])
y = torch.tensor([[3.0], [5.0], [7.0], [9.0]])

model = nn.Linear(1, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.05)

for epoch in range(100):
    loss = loss_fn(model(x), y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

print(loss.item())
```

### 預期輸出／結果

你會得到一個較小的 loss。不同優化器、learning rate 和資料下的效果會不同，不能只憑一個小例子判斷。

### 逐行解釋

與上一課相比，主要改變是 optimizer。Adam 是常用起點，但仍需在驗證資料上檢查設定。

## 再試一次：例子 2——把 Dropout 放進網絡

```python
model = nn.Sequential(
    nn.Linear(4, 16),
    nn.ReLU(),
    nn.Dropout(0.2),
    nn.Linear(16, 3)
)
print(model)
```

`Dropout(0.2)` 在訓練時隨機暫時關閉約 20% 的輸出。評估時要使用 `model.eval()`，讓 dropout 改為評估行為。

## 易錯位

### ❌ 用測試集選所有設定

反覆根據測試結果調 learning rate、層數，會令測試集不再公正。應先看驗證集。

### ❌ 只看訓練 loss

訓練 loss 下降但驗證 loss 上升，可能是過擬合信號。

## 本課小結

1. 驗證集協助選設定和發現過擬合；測試集應留到最後。
2. 標準化、Adam、dropout 都是改善訓練流程的工具。
3. early stopping 依驗證表現決定，不是固定訓練越久越好。
