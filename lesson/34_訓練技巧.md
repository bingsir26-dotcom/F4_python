## 新概念

### 1. 三份資料各有不同工作

- **訓練集**：模型可看答案，用來調整權重；
- **驗證集**：訓練途中不拿來更新權重，用來選輪數和設定；
- **測試集**：最後才使用，作較公正的總結。

### 2. 不只看訓練 loss

訓練 loss 持續下降很常見；若驗證 loss 先下降、後上升，便可能表示模型開始過度貼近訓練資料。通常可選驗證 loss 最低的一輪作為較好的停點，這種想法叫 early stopping。

> **延伸一提：** Adam、資料標準化和 dropout 都是日後可嘗試的訓練工具。不過先分清資料角色、讀懂驗證結果，比一次記住很多工具名稱更重要。

## 跟著做：例子 1——從驗證記錄找出較好的一輪

```python
history = [
    {"epoch": 1, "train_loss": 0.90, "valid_loss": 0.85},
    {"epoch": 2, "train_loss": 0.60, "valid_loss": 0.55},
    {"epoch": 3, "train_loss": 0.40, "valid_loss": 0.45},
    {"epoch": 4, "train_loss": 0.30, "valid_loss": 0.50}
]

best = min(history, key=lambda row: row["valid_loss"])
print("較好的停止輪數：", best["epoch"])
print("當時驗證 loss：", best["valid_loss"])
```

### 預期輸出

```text
較好的停止輪數： 3
當時驗證 loss： 0.45
```

### 逐行解釋

每個 Dictionary 保存一輪訓練後的兩個 loss。`min(..., key=...)` 會依 `valid_loss` 找最小的一筆，所以本例選出第 3 輪。

這些數字是小型示範記錄，不是正在訓練的真實模型；它的用途是先學會怎樣閱讀訓練日誌。第 39 課會再用相似方式保存完整實驗記錄。

## 再試一次：例子 2——把兩條 loss 線畫出來

**先執行例子 1**，再加入以下程式：

```python
import matplotlib.pyplot as plt

epochs = [row["epoch"] for row in history]
train_losses = [row["train_loss"] for row in history]
valid_losses = [row["valid_loss"] for row in history]

plt.plot(epochs, train_losses, marker="o", label="train loss")
plt.plot(epochs, valid_losses, marker="o", label="validation loss")
plt.xlabel("epoch")
plt.ylabel("loss")
plt.legend()
plt.show()
```

圖中訓練 loss 一直下降，但驗證 loss 在第 3 輪後上升。這正是不能只看訓練 loss 的原因。

## 易錯位

### ❌ 用測試集反覆選輪數和設定

每次根據測試集結果改設定，測試集便慢慢變成練習題，最後成績會太樂觀。

**✅ 修正：** 訓練途中看驗證集；完成選擇後才用測試集作最後檢查。

### ❌ 選訓練 loss 最低的一輪

訓練 loss 最低只代表最貼近已見資料，不一定代表面對新資料最好。

### ❌ 把一次驗證結果當成永久結論

資料量、分割方式和 random seed 都會影響結果。可記錄設定，必要時用不同分割再次檢查。

## 本課小結

1. 訓練集用來更新模型；驗證集用來選設定；測試集留到最後。
2. 驗證 loss 比訓練 loss 更適合判斷何時停止訓練。
3. 記錄資料分割和結果，才能讓模型比較更公平、可重現。
