# 第 42 課：常用解難模式——由題目想到程式

> **本課主題：把常見問題歸納為累加、計數、最大最小、篩選和模擬等可重用模式。**
>
> 解難不是背很多題目答案，而是看出不同題目背後相同的資料處理方式。

## 開始前：想一想

「計算總金幣」、「數有多少人及格」、「找最高分」看似不同，但它們都需要逐一讀取一串資料。差別主要在哪裡？

## 新概念

### 1. 五個常見模式

- **累加**：`total = 0`，每次加上目前值。
- **計數**：`count = 0`，符合條件才加 1。
- **最大最小**：保存目前最佳答案，再逐個比較。
- **篩選**：用空 List 收集符合條件資料。
- **模擬**：依規則逐步更新狀態。

### 2. 先用小例子推演

寫前先手算 3 至 5 筆資料，特別檢查空資料、剛好門檻、重複值等情況。

![解難模式的核心概念：累加、計數、最大值、篩選](/images/lesson-42-problem-solving-patterns.svg)

## 跟著做：例子 1——計算及格人數

```python
scores = [55, 72, 88, 49, 60]
count = 0

for score in scores:
    if score >= 60:
        count = count + 1

print("及格人數：", count)
```

### 預期輸出／結果

輸出「及格人數： 3」。

### 逐行解釋

`count` 在迴圈外由 0 開始；只有分數符合條件時才增加。`60` 是重要邊界值，應確定規則是「60 或以上」。

## 再試一次：例子 2——收集並找出最高及格分數

```python
passed_scores = []

for score in scores:
    if score >= 60:
        passed_scores.append(score)

print(passed_scores)
print(max(passed_scores))
```

先篩選資料，再在篩選後的 List 使用 `max()`。若可能沒有及格者，要先檢查 List 是否為空。

## 易錯位

### ❌ 在迴圈內重設答案

把 `count = 0` 或 `passed_scores = []` 放進迴圈會令每輪重新開始。初始化通常在迴圈外。

### ❌ 對空 List 直接 `max()`

沒有元素時 `max([])` 會出錯。先用 `if passed_scores:` 或 `len(passed_scores) > 0` 檢查。

## 本課小結

1. 許多解難題可歸納成少量重用模式。
2. 初始值要放在迴圈外，並配合題目選擇。
3. 空資料和門檻資料是必要測試。
