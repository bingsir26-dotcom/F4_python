# 第 42 課：常用解難模式——由題目想到迴圈

> **本課主題：看見題目中的資料，辨認要「累加、計數、找最大值、篩選」還是「逐步模擬」。**
>
> 解難不靠背答案。很多不同題目都在重複使用同一種迴圈骨架；能說出骨架的工作，便較容易下手。

## 今課可以做到甚麼？

- 由問題選擇累加、計數、找最大值或篩選的基本寫法；
- 為變數設定合理的初始值；
- 先用少量資料手算，檢查程式是否符合規則。

## 開始前：想一想

「計算總金幣」、「數達標回合」、「找最高金幣」、「收集達標紀錄」都要逐個讀取金幣數字。它們最重要的不同，是每次讀到一個數字後要怎樣更新答案。

## 新概念

### 1. 先問：答案是甚麼類型？

| 題目想要的答案 | 常用初始值 | 每次處理一項時 |
| --- | --- | --- |
| 總和 | `total = 0` | 加上目前值 |
| 數量 | `count = 0` | 符合條件才加 1 |
| 最高值 | 第一個值或 `None` | 和目前最佳比較 |
| 一批符合項目 | `selected = []` | 符合條件才加入 |

### 2. 小例子先手算

在寫程式前，用 3 至 5 個數字寫下每一步的 `count` 或 `total`。這能檢查門檻是否寫對、是否漏掉第一項，也能幫你選對初始值。

![四種常用迴圈模式以同一串金幣展示不同的答案：總金幣、達標回合數、最高金幣和達標紀錄](/images/lesson-42-problem-solving-patterns.svg)

## 跟著做：例子 1——數出達標回合數

```python
gold_values = [55, 72, 88, 49, 60]
target_count = 0

for gold in gold_values:
    if gold >= 60:
        target_count = target_count + 1

print("達標回合數：", target_count)
```

### 預期輸出

```text
達標回合數： 3
```

### 逐行解釋

答案是「回合數」，所以先用 `0` 作初始值。迴圈逐個查看 `gold_values` 中的金幣；只有金幣大於或等於 60 時，`target_count` 才加 1。

不要把 `target_count = 0` 放進迴圈內，否則每次都會重新由 0 開始計算。

## 再試一次：例子 2——收集達標金幣紀錄

```python
gold_values = [55, 72, 88, 49, 60]
target_gold_values = []

for gold in gold_values:
    if gold >= 60:
        target_gold_values.append(gold)

print("達標金幣紀錄：", target_gold_values)
print("最高達標金幣：", max(target_gold_values))
```

### 預期輸出

```text
達標金幣紀錄： [72, 88, 60]
最高達標金幣： 88
```

這次答案是一批資料，所以初始值是空 List `[]`。符合條件的金幣用 `append()` 加入。資料收集後才用 `max()` 找其中最大值。

## 易錯位

### ❌ 在迴圈內重新設定累積答案

```python
for gold in gold_values:
    target_count = 0
```

**原因：** 每次循環都抹掉之前的計算。

**✅ 修正：** 初始值放在迴圈前。

### ❌ 使用錯誤初始值

若要計數卻從 `1` 開始，答案會平白多一個。

**✅ 修正：** 想清楚「未看任何資料時，答案應是多少」。數量和總和通常是 0；收集結果通常是空 List。

### ❌ 對空 List 使用 `max()`

若沒有回合達標，`target_gold_values` 是空的，`max(target_gold_values)` 會出錯。

**✅ 修正：** 先檢查 `if target_gold_values:`，再找最大值。

## 你來做

### 基礎題：計算總金幣

給定一個金幣 List，用 `for` 和 `total` 算出總數，不使用 `sum()`。

### 標準題：找出最高金幣

用迴圈找出一串**至少有一個數字**的金幣中的最高值，不使用 `max()`。

### 挑戰題：設計自己的模式表

選一個生活問題，例如統計活動完成次數或收集已完成任務名稱。寫出答案類型、初始值、每次如何更新。

## 本課小結

1. 先判斷答案是總和、數量、一個最佳值，還是一批資料。
2. 初始值要代表「還沒處理任何資料時」的答案。
3. 用小資料手算每一步，可以及早發現規則錯誤。
