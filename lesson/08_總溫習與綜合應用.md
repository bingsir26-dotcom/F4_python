## 開始前：想一想

假設你想為老師製作一個「迷你成績管理器」：

```text
輸入多個分數；
輸入 q 時停止；
顯示所有分數和平均分；
為每一個分數顯示等級。
```

你已學過的哪一個工具能負責每一件事？請先自己配對：`input()`、列表、`while`、`for`、`if`。

## 新概念

### 1. 先把大任務拆成小任務

寫作品前，不要一開始就寫很長的程式。先列出它需要完成的步驟：

1. 建立一個空列表保存分數；
2. 重複詢問使用者輸入；
3. 輸入 `q` 時停止；
4. 把數字分數加入列表；
5. 用 `for` 計算總和與平均；
6. 用 `if`／`elif` 顯示各分數等級。

![單元一工具地圖：輸入、列表、判斷、for、while 如何組合成作品](/images/lesson-08-project-map.svg)

### 2. 每個工具做自己擅長的工作

| 工具 | 在作品中的工作 |
| --- | --- |
| `input()` | 取得使用者輸入 |
| `list` | 保存多筆分數 |
| `while` | 不斷詢問，直到輸入 `q` |
| `for` | 逐一處理所有分數 |
| `if`／`elif`／`else` | 為分數決定等級 |
| `len()` | 計算共有幾個分數 |

### 3. 寫完後一定要測試

至少測試三種情況：

- 正常情況：輸入幾個有效分數；
- 邊界情況：輸入 `59`、`60`、`79`、`80`、`89`、`90`，確認每個等級門檻都正確；
- 特別情況：一開始就輸入 `q`，程式會怎樣？

## 跟著做：例子 1——迷你成績管理器

> **本版本的輸入規則：** 請輸入 `q` 結束，或輸入純整數分數，例如 `80`。程式會先用 `.strip()` 移除前後空格；輸入 `80分` 或中文數字時仍不能轉成整數，先不要這樣輸入。

```python
scores = []

while True:
    user_input = input("輸入分數（輸入 q 結束）：").strip()

    if user_input == "q":
        break

    scores.append(int(user_input))

print("所有分數：", scores)
```

### 一次示範

```text
輸入分數（輸入 q 結束）：80
輸入分數（輸入 q 結束）：95
輸入分數（輸入 q 結束）：70
輸入分數（輸入 q 結束）：q
所有分數： [80, 95, 70]
```

### 逐行解釋

```python
scores = []
```

建立一個空列表，稍後用來保存分數。

```python
while True:
```

程式會一直詢問輸入；真正停止的位置由 `break` 決定。

```python
if user_input == "q":
    break
```

如果使用者輸入 `q`，不把它當作分數，而是立即離開迴圈。

```python
scores.append(int(user_input))
```

`.strip()` 先移除輸入前後的空格；不是 `q` 的內容才轉為整數並加入列表。

## 再試一次：例子 2——計算平均與顯示等級

在例子 1 的最後加入以下程式：

```python
total = 0

for score in scores:
    total = total + score

average = total / len(scores)
print("平均分：", average)

for score in scores:
    if score >= 90:
        print(score, "A")
    elif score >= 80:
        print(score, "B")
    elif score >= 60:
        print(score, "C")
    else:
        print(score, "F")
```

這段程式先用第一個 `for` 計算總分，再用第二個 `for` 逐一為每個分數判斷等級。

> **先試再加：** 如果 `scores` 是空列表，`total / len(scores)` 不能計算。挑戰題會處理這個情況。

## 易錯位

### ❌ 把 `q` 也轉成整數

**錯誤寫法**

```python
scores.append(int(user_input))

if user_input == "q":
    break
```

使用者輸入 `q` 時，Python 會先嘗試 `int("q")`，因此出錯。

**✅ 改成這樣**

```python
if user_input == "q":
    break

scores.append(int(user_input))
```

先判斷是否離開，再轉換真正的數字。

### ❌ 在 `for` 內重設總分

**錯誤寫法**

```python
for score in scores:
    total = 0
    total = total + score
```

**✅ 改成這樣**

```python
total = 0
for score in scores:
    total = total + score
```

### ❌ 空列表仍然計算平均

**錯誤寫法**

```python
average = total / len(scores)
```

如果 `scores` 沒有任何分數，`len(scores)` 是 `0`，不能作除數。

**✅ 改成這樣**

```python
if len(scores) > 0:
    average = total / len(scores)
    print("平均分：", average)
else:
    print("沒有輸入分數。")
```
