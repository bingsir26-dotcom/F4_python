## 8.2 快速練習（暖身）

練習 1：判斷奇數偶數

```python
num = int(input("輸入數字："))

if num % 2 == 0:
    print("偶數")
else:
    print("奇數")
```

```python

```

🎮 8.3 綜合任務（主作品）

👉 建議用這個當「本單元作品 / 評核」

🎯 作品：成績管理系統（完整版）

功能要求：

輸入多個成績（while）

存入列表（list）

顯示所有成績（for）

計算平均（for）

判斷等級（if）

✅ 參考答案

```python
scores = []

while True:
    s = input("輸入成績（輸入 q 離開）：")

    if s == "q":
        break

    scores.append(int(s))

print("所有成績：", scores)

# 計算平均
total = 0
for s in scores:
    total = total + s

avg = total / len(scores)
print("平均：", avg)

# 顯示等級
for s in scores:
    if s >= 90:
        print(s, "A")
    elif s >= 80:
        print(s, "B")
    elif s >= 60:
        print(s, "C")
    else:
        print(s, "F")
```
