# 資料清洗與篩選（pandas 進階一）

這一節的目標，是讓學生從「能把資料讀進 Python」進步到「能整理資料、找出有用資訊」。資料分析不是直接把資料丟進 AI，而是要先檢查資料是否完整、正確和可用。isna()、dropna() 和 fillna() 可用來找出、刪除或補上缺失資料；sort_values() 可按欄位排序資料。pandas.pydata+2

完成一個簡單的成績資料整理任務。

## 2. 什麼是資料清洗？

資料清洗（Data Cleaning）就是把原本可能有問題的資料整理好，讓資料可以用來分析。

真實資料常見問題：

有些資料沒有填寫。

有些數字輸入錯誤。

有些資料重複。

欄位名稱不一致。

資料格式混亂。

你可以跟學生說：

垃圾進，垃圾出。  
如果給 AI 或分析工具的資料有問題，得出的結果也可能有問題。

## 3. 本課範例資料

先建立一張成績表。這張表刻意加入一些缺失值，方便練習。

```python
import pandas as pd

data = {
    "姓名": ["Tom", "Mary", "John", "Alice", "Ben", "Cindy"],
    "數學": [80, 90, None, 65, 50, 78],
    "英文": [75, None, 88, 70, 55, 82],
    "班級": ["F4A", "F4A", "F4A", "F4B", "F4B", "F4B"]
}

df = pd.DataFrame(data)

print(df)
```

輸出概念如下：

| 姓名 | 數學 | 英文 | 班級 |
| --- | --- | --- | --- |
| Tom | 80 | 75 | F4A |
| Mary | 90 | 空白 | F4A |
| John | 空白 | 88 | F4A |
| Alice | 65 | 70 | F4B |
| Ben | 50 | 55 | F4B |
| Cindy | 78 | 82 | F4B |

在 pandas 中，空白或缺失資料通常會顯示為 NaN；這代表 Not a Number，可理解為「沒有資料」。isna() 會以 True 標示缺失值。pandas.pydata+1

## 4. 找出缺失值：isna()

## 4.1 查看每一格是否缺失

```python
print(df.isna())
```

如果某格是 True，代表該位置缺少資料；False 代表有資料。geeksforgeeks

例如：

| 姓名 | 數學 | 英文 | 班級 |
| --- | --- | --- | --- |
| Tom | False | False | False |
| Mary | False | True | False |
| John | True | False | False |

## 4.2 計算每一欄缺失多少資料

```python
print(df.isna().sum())
```

可能結果：

```python
```

姓名    0

數學    1

英文    1

班級    0

dtype: int64

意思是：

「數學」有 1 個缺失值。

「英文」有 1 個缺失值。

這是資料分析的第一步：先知道問題在哪裡。

## 5. 刪除缺失資料：dropna()

如果某一列資料缺得太多，或缺失資料無法補回，可以選擇刪除。

```python
clean_df = df.dropna()

print(clean_df)
dropna() 會移除包含缺失值的列；原本的 df 不會自動改變，結果會存到新的 clean_df。geeksforgeeks+1
```

輸出概念：

| 姓名 | 數學 | 英文 | 班級 |
| --- | --- | --- | --- |
| Tom | 80 | 75 | F4A |
| Alice | 65 | 70 | F4B |
| Ben | 50 | 55 | F4B |
| Cindy | 78 | 82 | F4B |

## 5.1 刪除前要思考

直接刪除資料雖然簡單，但可能有問題：

如果缺失資料很多，刪掉後資料量會變少。

如果剛好刪掉某一類學生，分析可能不公平。

有些資料可以補回，不一定要刪除。

所以，dropna() 不是永遠最好的方法。

## 6. 補上缺失資料：fillna()

另一種方法是保留原本資料列，再把缺失值補上。  
fillna() 可以把缺失值替換成指定數值，例如 0，也可以填入該欄平均值。pandas.pydata+2

## 6.1 用 0 補上缺失值

```python
df_zero = df.fillna(0)

print(df_zero)
```

結果概念：

| 姓名 | 數學 | 英文 | 班級 |
| --- | --- | --- | --- |
| Tom | 80 | 75 | F4A |
| Mary | 90 | 0 | F4A |
| John | 0 | 88 | F4A |
| Alice | 65 | 70 | F4B |
| Ben | 50 | 55 | F4B |
| Cindy | 78 | 82 | F4B |

適合情況：

空白真的代表沒有分數。

空白可視為 0。

只是測試練習資料。

但要提醒學生：如果學生只是缺考、遲交或資料未輸入，直接補 0 未必公平。

## 6.2 用平均值補數學缺失資料

```python
math_mean = df["數學"].mean()

df["數學"] = df["數學"].fillna(math_mean)

print(df)
```

這裡先計算數學欄的平均值，再用平均值填補空白位置。pandas.pydata+1

## 6.3 用每欄平均值補缺失資料

```python
df["數學"] = df["數學"].fillna(df["數學"].mean())
df["英文"] = df["英文"].fillna(df["英文"].mean())

print(df)
```

這是很常見的入門做法：

數學空白，用數學平均補。

英文空白，用英文平均補。

## 6.4 教學提醒

補資料不是「隨便填一個數字」。  
在真正的資料分析中，要根據資料的意思決定方法：

| 情況 | 可以考慮的方法 |
| --- | --- |
| 缺失很少，而且不重要 | 刪除該列 |
| 缺失代表 0 | 用 fillna(0) |
| 數值資料少量缺失 | 用平均值或中位數 |
| 資料非常重要 | 回去重新收集或確認 |

## 7. 篩選資料列

資料篩選就是只找出符合條件的資料。  
這和 Excel 的「篩選」功能很相似。

## 7.1 找出數學及格學生

```python
passed_math = df[df["數學"] >= 60]

print(passed_math)
```

這段程式的意思是：

df["數學"] >= 60：逐一判斷每位學生是否達到 60 分。

df[...]：只保留判斷結果為 True 的資料列。

以欄位條件篩選資料列是 pandas 很常用的資料分析操作。youtubegeeksforgeeks

## 7.2 找出英文不及格學生

```python
failed_english = df[df["英文"] < 60]

print(failed_english)
```

## 7.3 同時符合兩個條件

例如找出「數學及格，而且英文及格」的學生：

```python
passed_both = df[(df["數學"] >= 60) & (df["英文"] >= 60)]

print(passed_both)
```

注意：

& 代表「而且」。

每個條件都要放在括號內。

## 7.4 符合其中一個條件

例如找出「數學或英文有一科不及格」的學生：

```python
need_help = df[(df["數學"] < 60) | (df["英文"] < 60)]

print(need_help)
```

注意：

| 代表「或」。

這個篩選可用來找出需要額外協助的學生。

## 8. 欄位運算與新欄位

資料分析常常需要從原本欄位計算出新資料。

## 8.1 新增總分欄位

```python
df["總分"] = df["數學"] + df["英文"]

print(df)
```

結果概念：

| 姓名 | 數學 | 英文 | 總分 |
| --- | --- | --- | --- |
| Tom | 80 | 75 | 155 |
| Mary | 90 | 74 | 164 |
| John | 73 | 88 | 161 |

這一步很重要，因為它表示：

資料分析不只是看原始資料，也會創造能回答問題的新欄位。

## 8.2 新增平均分欄位

```python
df["平均分"] = (df["數學"] + df["英文"]) / 2

print(df)
```

## 8.3 新增是否及格欄位

```python

print(df)
```

輸出會顯示 True 或 False。

## 10. 完整示範：成績資料整理

這份程式可以當作本課的老師示範，包含：

建立資料。

查看缺失值。

用平均值補資料。

建立總分與平均分。

找出及格學生。

排出前三名。

```python
import pandas as pd

data = {
    "姓名": ["Tom", "Mary", "John", "Alice", "Ben", "Cindy"],
    "數學": [80, 90, None, 65, 50, 78],
    "英文": [75, None, 88, 70, 55, 82],
    "班級": ["F4A", "F4A", "F4A", "F4B", "F4B", "F4B"]
}

df = pd.DataFrame(data)

# 1. 查看缺失資料
print("缺失值統計：")
print(df.isna().sum())

# 2. 用平均值補上缺失資料
df["數學"] = df["數學"].fillna(df["數學"].mean())
df["英文"] = df["英文"].fillna(df["英文"].mean())

# 3. 建立新欄位
df["總分"] = df["數學"] + df["英文"]
df["平均分"] = df["總分"] / 2

# 4. 篩選及格學生
passed = df[df["平均分"] >= 60]
print("\n及格學生：")
print(passed)

# 5. 顯示總分前三名
top3 = df.sort_values(by="總分", ascending=False).head(3)
print("\n總分前三名：")
print(top3)
```

## 11. 常見錯誤

錯誤 1：欄位名稱寫錯

```python
df["数学"]
```

如果原欄名是「數學」，卻寫成「数学」，就會出現錯誤。  
欄位名稱必須完全一致。

錯誤 2：沒有先處理缺失值就計算

如果分數有缺失值，總分和平均分也可能變成 NaN。  
所以通常應先檢查並處理缺失資料。

錯誤 3：排序後忘記儲存或印出

```python
df.sort_values(by="總分", ascending=False)
```

這行可以執行，但若沒有 print() 或存入新變量，學生不容易看到結果。

建議寫：

```python
rank_df = df.sort_values(by="總分", ascending=False)
print(rank_df)
```

錯誤 4：多條件篩選忘記加括號

錯誤示範：

```python
df[df["數學"] >= 60 & df["英文"] >= 60]
```

正確寫法：

```python
df[(df["數學"] >= 60) & (df["英文"] >= 60)]
```

import pandas as pd

data = {
    "姓名": ["Amy", "Bob", "Chris", "Daisy", "Eric", "Fiona"],
    "數學": [85, None, 72, 95, 58, 66],
    "英文": [78, 60, None, 88, 55, 70],

df = pd.DataFrame(data)

df["數學"] = df["數學"].fillna(df["數學"].mean())

df["總分"] = df["數學"] + df["英文"]

passed = df[df["平均分"] >= 60]

need_help = df[(df["數學"] < 60) | (df["英文"] < 60)]
