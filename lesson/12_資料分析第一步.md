## 開始前：想一想

以下是一班五位同學的數學分數：

```python
scores = [78, 55, 91, 72, 84]
```

只看這一行，你可以問出甚麼問題？

- 全班平均分是多少？
- 有多少人及格？

這就是資料分析的起點：**不是先找很複雜的工具，而是先問一個值得回答的問題。**

先猜的目的不是要立刻答對，而是讓你執行程式後能檢查自己的感覺。

## 新概念

### 1. 真實資料常以 CSV 保存

CSV 是一種簡單的表格檔案格式；每一行是一筆資料，各欄之間以逗號分隔。例如：

```text
姓名,班別,數學,英文
小美,F4A,82,76
小強,F4A,65,70
```

第一行是**欄位名稱**；之後每一行是一筆**紀錄**。下一課會由你已學過的 Dictionary 走到資料表，之後再用 pandas 直接讀取 CSV。

### 2. 先問資料能回答甚麼

好的問題要具體，例如「哪一班平均數學成績最高？」、「讀書時間較長的同學，成績是否較高？」。只問「這份資料有甚麼？」很難知道下一步要做甚麼。


### 1. 資料、問題和結論

同一串分數可以有不同用途：

| 部分 | 例子 |
|---|---|
| 資料 | `[78, 55, 91, 72, 84]` |
| 問題 | 全班平均分是多少？ |
| 程式處理 | 加總後除以人數 |
| 結論 | 平均分是 76 分 |

程式不會自動告訴你甚麼問題值得問；你要先決定問題，再寫程式處理資料。

### 2. 你已經有分析資料的工具

第一單元學過的工具，已經足夠處理小型資料：

```python
scores = [78, 55, 91, 72, 84]  # 保存資料
for score in scores:           # 逐一讀取
    ...
if score >= 60:                # 判斷資料
    ...
```

之後學 pandas，不是把這些概念丟掉；而是讓你能更方便地處理有姓名、班別和多科成績的大型資料表。

### 3. 先確認你正在計算甚麼

```python
average = total / len(scores)
```

這行的意思是「總分除以分數數量」。`len(scores)` 會數出 List 有多少個元素。分析時要清楚：

- `total` 是全部分數的總和；
- `len(scores)` 是學生人數；
- `average` 才是平均分。

## 跟著做：例子 1——計算全班平均分

```python
scores = [78, 55, 91, 72, 84]
total = 0

for score in scores:
    total = total + score

average = total / len(scores)
print("全班平均分：", average)
```

### 預期輸出

```text
全班平均分： 76.0
```

### 逐行解釋

```python
scores = [78, 55, 91, 72, 84]
```

建立一個 List，保存五位同學的分數。

```python
total = 0
```

建立 `total`，先從 0 開始累積總分。

```python
for score in scores:
    total = total + score
```

`for` 每次取出一個分數，加入 `total`。五輪之後，`total` 會是 380。

```python
average = total / len(scores)
```

用總分 380 除以 5 位學生，得到平均分 76.0。

## 再試一次：例子 2——計算及格人數

這次不再把每個分數加起來，而是數一數多少個分數達到 60：

```python
scores = [78, 55, 91, 72, 84]
passed_count = 0

for score in scores:
    if score >= 60:
        passed_count = passed_count + 1

print("及格人數：", passed_count)
```

### 預期輸出

```text
及格人數： 4
```

### 本次改了甚麼？

- `total` 改成 `passed_count`；
- 只有分數 `>= 60` 時才加 1；
- 程式回答的問題由「平均多少分？」改成「多少人及格？」。

## 易錯位

### ❌ 把人數寫死

```python
average = total / 5
```

**問題：** 現在剛好有五個分數；加入或刪除資料後，程式會算錯。

**✅ 改成這樣：**

```python
average = total / len(scores)
```

### ❌ 忘記在 `for` 前建立累積變數

```python
for score in scores:
    total = total + score
```

**問題：** `total` 還沒有任何初始值。

**✅ 改成這樣：**

```python
total = 0
for score in scores:
    total = total + score
```

### ❌ 把 `if` 放在迴圈外面

```python
for score in scores:
    pass

if score >= 60:
    passed_count = passed_count + 1
```

**問題：** 這樣只會檢查最後一個分數。

**✅ 改成這樣：** 把 `if` 縮排在 `for` 內，每個分數都檢查一次。
