## 開始前：想一想

以下是五個遊戲回合獲得的金幣：

```python
gold_values = [78, 55, 91, 72, 84]
```

只看這一行，你可以問出甚麼問題？

- 平均每回合獲得多少金幣？
- 有多少回合達到 60 枚金幣？
- 哪些回合低於 60 枚？

這就是資料分析的起點：**不是先找很複雜的工具，而是先問一個值得回答的問題。**

### 先猜一猜

不用計算機，先猜這五個回合的平均金幣比較接近哪一個？

```text
大約 60 枚／大約 75 枚／大約 90 枚
```

先猜的目的不是要立刻答對，而是讓你執行程式後能檢查自己的感覺。

## 新概念

### 1. 真實資料常以 CSV 保存

CSV 是一種簡單的表格檔案格式；每一行是一筆資料，各欄之間以逗號分隔。例如：

```text
玩家,關卡,金幣,完成時間
Nova,1,82,76
Rex,1,65,70
```

第一行是**欄位名稱**；之後每一行是一筆**紀錄**。下一課會由你已學過的 Dictionary 走到資料表，之後再用 pandas 直接讀取 CSV。

> **資料使用提醒：** 本課的玩家和金幣都是虛構資料。若日後分析真實紀錄，先確認資料來源是否允許使用；課堂範例不要保留姓名、帳號、聯絡方式等可識別個人的資料。

### 2. 先問資料能回答甚麼

好的問題要具體，例如「哪一關平均金幣最高？」、「完成時間較短的回合，金幣是否較多？」。只問「這份資料有甚麼？」很難知道下一步要做甚麼。

### 3. 資料、問題和結論

同一串金幣可以有不同用途：

| 部分 | 例子 |
|---|---|
| 資料 | `[78, 55, 91, 72, 84]` |
| 問題 | 平均每回合有多少金幣？ |
| 程式處理 | 加總後除以回合數 |
| 結論 | 平均是 76 枚金幣 |

程式不會自動告訴你甚麼問題值得問；你要先決定問題，再寫程式處理資料。

### 4. 你已經有分析資料的工具

第一單元學過的工具，已經足夠處理小型資料：

```text
gold_values：保存所有回合金幣
for：逐一讀取每個金幣數量
if：判斷某一個回合是否符合條件
```

你不需要忘記前面學過的 List、`for` 和 `if`。pandas 不是另一種完全不同的思考方式；它只是把「很多回合、很多欄資料」整理得更方便。

### 5. 先確認你正在計算甚麼

```python
average_gold = total_gold / len(gold_values)
```

這行的意思是「總金幣除以回合數量」。`len(gold_values)` 會數出 List 有多少個元素。分析時要清楚：

- `total_gold` 是全部金幣的總和；
- `len(gold_values)` 是回合數；
- `average_gold` 才是平均金幣。

## 跟著做：例子 1——計算平均金幣

```python
gold_values = [78, 55, 91, 72, 84]
total_gold = 0

for gold in gold_values:
    total_gold = total_gold + gold

average_gold = total_gold / len(gold_values)
print("平均金幣：", average_gold)
```

### 預期輸出

```text
平均金幣： 76.0
```

### 逐行解釋

```python
gold_values = [78, 55, 91, 72, 84]
```

建立一個 List，保存五個遊戲回合的金幣數量。

```python
total_gold = 0
```

建立 `total_gold`，先從 0 開始累積金幣。

```python
for gold in gold_values:
    total_gold = total_gold + gold
```

`for` 每次取出一個回合的金幣，加入 `total_gold`。五輪之後，`total_gold` 會是 380。

```python
average_gold = total_gold / len(gold_values)
```

用總金幣 380 除以 5 個回合，得到平均金幣 76.0。

## 再試一次：例子 2——計算達標回合數

這次不再把每個金幣加起來，而是數一數多少個回合達到 60 枚：

```python
gold_values = [78, 55, 91, 72, 84]
target_count = 0

for gold in gold_values:
    if gold >= 60:
        target_count = target_count + 1

print("達標回合數：", target_count)
```

### 預期輸出

```text
達標回合數： 4
```

### 本次改了甚麼？

- `total_gold` 改成 `target_count`；
- 只有金幣 `>= 60` 時才加 1；
- 程式回答的問題由「平均有多少金幣？」改成「有多少回合達標？」。

## 易錯位

### ❌ 把回合數寫死

```python
average_gold = total_gold / 5
```

**問題：** 現在剛好有五個回合；加入或刪除資料後，程式會算錯。

**✅ 改成這樣：**

```python
average_gold = total_gold / len(gold_values)
```

### ❌ 忘記在 `for` 前建立累積變數

```python
for gold in gold_values:
    total_gold = total_gold + gold
```

**問題：** `total_gold` 還沒有任何初始值。

**✅ 改成這樣：**

```python
total_gold = 0
for gold in gold_values:
    total_gold = total_gold + gold
```

### ❌ 把 `if` 放在迴圈外面

```python
for gold in gold_values:
    pass

if gold >= 60:
    target_count = target_count + 1
```

**問題：** 這樣只會檢查最後一個回合。

**✅ 改成這樣：** 把 `if` 縮排在 `for` 內，每個回合都檢查一次。
