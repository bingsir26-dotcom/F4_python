### 2. 每一位學生是一筆有名稱的資料

```python
student = {"name": "小美", "score": 80}
```

Dictionary 讓一筆資料有清楚的標籤：`"name"` 對應姓名，`"score"` 對應分數。多位學生可放進同一個 List：

```python
students = [
    {"name": "小美", "score": 80},
    {"name": "小強", "score": 65}
]
```

## 跟著做：例子 1——固定資料版：顯示分數和平均分

先不要輸入資料，直接使用兩位學生的固定資料。以下程式可由第一行單獨執行：

```python
students = [
    {"name": "小美", "score": 80},
    {"name": "小強", "score": 65}
]

total = 0

for student in students:
    print(student["name"], "：", student["score"], "分")
    total = total + student["score"]

average = total / len(students)
print("平均分：", average)
```

### 預期輸出／結果

```text
小美 ： 80 分
小強 ： 65 分
平均分： 72.5
```

### 逐行解釋

```python
students = [
    {"name": "小美", "score": 80},
    {"name": "小強", "score": 65}
]
```

`students` 是 List，裡面有兩個 Dictionary；每個 Dictionary 保存一位學生的姓名和分數。

```python
for student in students:
```

`for` 逐一取出 List 裡的一位學生。第一輪的 `student` 是小美的資料，第二輪是小強的資料。

```python
print(student["name"], "：", student["score"], "分")
total = total + student["score"]
```

用標籤取出姓名和分數來顯示，同時把分數累加到 `total`。

```python
average = total / len(students)
```

`len(students)` 是學生人數。總分 145 除以 2，得到平均分 72.5。

## 再試一次：例子 2——只加一個「成績等級」函式

這次只加入一件新事：用 `get_grade()` 決定成績等級。以下仍是完整、可單獨執行的程式：

```python
def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 60:
        return "C"
    else:
        return "F"

students = [
    {"name": "小美", "score": 80},
    {"name": "小強", "score": 65}
]

total = 0

for student in students:
    score = student["score"]
    grade = get_grade(score)
    print(f'{student["name"]}：{score} 分，{grade}')
    total = total + score

average = total / len(students)
print("平均分：", average)
```

### 預期輸出／結果

```text
小美：80 分，B
小強：65 分，C
平均分： 72.5
```

### 這次加入了甚麼？

```python
def get_grade(score):
```

函式收到一個分數，依照條件回傳一個等級文字。主程式只要寫 `get_grade(score)`，不用每次重寫整段 `if`、`elif`。

```python
grade = get_grade(score)
```

這行把函式回傳的結果保存到 `grade`，再顯示在每位學生的分數後面。

## 完整互動版——自己輸入學生資料

現在才把固定資料換成 `while` 和 `input()`。以下程式可由第一行單獨執行；輸入小寫 `q` 時結束。

```python
def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 60:
        return "C"
    else:
        return "F"

students = []

while True:
    name = input("學生姓名（輸入 q 結束）：")

    if name == "q":
        break

    score = int(input("分數："))
    students.append({"name": name, "score": score})

if len(students) == 0:
    print("沒有輸入學生資料。")
else:
    total = 0

    for student in students:
        score = student["score"]
        grade = get_grade(score)
        print(f'{student["name"]}：{score} 分，{grade}')
        total = total + score

    average = total / len(students)
    print("平均分：", average)
```

### 一次示範

```text
學生姓名（輸入 q 結束）：小美
分數：80
學生姓名（輸入 q 結束）：小強
分數：65
學生姓名（輸入 q 結束）：q
小美：80 分，B
小強：65 分，C
平均分： 72.5
```

這個版本多了「收集資料」的部分，但計算平均分和決定等級的做法，與前兩個例子相同。

## 易錯位

### ❌ 先把 `q` 轉成分數

```python
score = int(input("分數："))
if name == "q":
    break
```

如果已輸入 `q`，程式根本不應再問分數。

**✅ 修正：** 先檢查 `name == "q"`，再讀取和轉換分數。

### ❌ 把一位學生的資料直接加入成文字

```python
students.append(name)
```

這樣只保存名字，之後沒有對應的分數。

**✅ 修正：** 把姓名和分數一起放進 Dictionary。

```python
students.append({"name": name, "score": score})
```

### ❌ 空 List 也計算平均

```python
average = total / len(students)
```

若一開始就輸入 `q`，`students` 是空的，`len(students)` 是 0，不能作除數。

**✅ 修正：** 先判斷 `len(students) == 0`，沒有資料時只顯示提示。
