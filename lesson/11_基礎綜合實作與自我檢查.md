### 2. 每一個角色是一筆有名稱的資料

```python
character = {"name": "Nova", "gold": 80}
```

Dictionary 讓一筆資料有清楚的標籤：`"name"` 對應角色名稱，`"gold"` 對應金幣。多個角色可放進同一個 List：

```python
characters = [
    {"name": "Nova", "gold": 80},

```

## 跟著做：例子 1——固定資料版：顯示金幣和平均值

先不要輸入資料，直接使用兩個角色的固定資料。以下程式可由第一行單獨執行：

```python
characters = [
    {"name": "Nova", "gold": 80},
    {"name": "Rex", "gold": 65}
]

total_gold = 0

for character in characters:
    print(character["name"], "：", character["gold"], "枚金幣")
    total_gold = total_gold + character["gold"]

average_gold = total_gold / len(characters)
print("平均金幣：", average_gold)
```

### 預期輸出／結果

```text
Nova ： 80 枚金幣
Rex ： 65 枚金幣
平均金幣： 72.5
```

### 逐行解釋

```python
characters = [
    {"name": "Nova", "gold": 80},
    {"name": "Rex", "gold": 65}
]
```

`characters` 是 List，裡面有兩個 Dictionary；每個 Dictionary 保存一個角色的名稱和金幣。

```python
for character in characters:
```

`for` 逐一取出 List 裡的一個角色。第一輪的 `character` 是 Nova 的資料，第二輪是 Rex 的資料。

```python
print(character["name"], "：", character["gold"], "枚金幣")
total_gold = total_gold + character["gold"]
```

用標籤取出角色名稱和金幣來顯示，同時把金幣累加到 `total_gold`。

```python
average_gold = total_gold / len(characters)
```

`len(characters)` 是角色數量。總金幣 145 除以 2，得到平均金幣 72.5。

## 再試一次：例子 2——只加一個「角色稱號」函式

這次只加入一件新事：用 `get_title()` 決定角色稱號。以下仍是完整、可單獨執行的程式：

```python
def get_title(gold):
    if gold >= 90:
        return "傳奇玩家"
    elif gold >= 80:
        return "高手"
    elif gold >= 60:
        return "冒險者"
    else:
        return "新手"

characters = [
    {"name": "Nova", "gold": 80},
    {"name": "Rex", "gold": 65}
]

total_gold = 0

for character in characters:
    gold = character["gold"]
    title = get_title(gold)
    print(f'{character["name"]}：{gold} 枚金幣，{title}')
    total_gold = total_gold + gold

average_gold = total_gold / len(characters)
print("平均金幣：", average_gold)
```

### 預期輸出／結果

```text
Nova：80 枚金幣，高手
Rex：65 枚金幣，冒險者
平均金幣： 72.5
```

### 這次加入了甚麼？

```python
def get_title(gold):
```

函式收到一個金幣數量，依照條件回傳一個稱號文字。主程式只要寫 `get_title(gold)`，不用每次重寫整段 `if`、`elif`。

```python
title = get_title(gold)
```

這行把函式回傳的結果保存到 `title`，再顯示在每個角色的金幣後面。

## 完整互動版——自己輸入角色資料

現在才把固定資料換成 `while` 和 `input()`。以下程式可由第一行單獨執行；輸入小寫 `q` 時結束。

```python
def get_title(gold):
    if gold >= 90:
        return "傳奇玩家"
    elif gold >= 80:
        return "高手"
    elif gold >= 60:
        return "冒險者"
    else:
        return "新手"

characters = []

while True:
    name = input("角色名稱（輸入 q 結束）：")

    if name == "q":
        break

    gold = int(input("金幣："))
    characters.append({"name": name, "gold": gold})

if len(characters) == 0:
    print("沒有輸入角色資料。")
else:
    total_gold = 0

    for character in characters:
        gold = character["gold"]
        title = get_title(gold)
        print(f'{character["name"]}：{gold} 枚金幣，{title}')
        total_gold = total_gold + gold

    average_gold = total_gold / len(characters)
    print("平均金幣：", average_gold)
```

### 一次示範

```text
角色名稱（輸入 q 結束）：Nova
金幣：80
角色名稱（輸入 q 結束）：Rex
金幣：65
角色名稱（輸入 q 結束）：q
Nova：80 枚金幣，高手
Rex：65 枚金幣，冒險者
平均金幣： 72.5
```

這個版本多了「收集資料」的部分，但計算平均金幣和決定稱號的做法，與前兩個例子相同。

## 易錯位

### ❌ 先把 `q` 轉成金幣

```python
gold = int(input("金幣："))
if name == "q":
    break
```

如果已輸入 `q`，程式根本不應再問金幣。

**✅ 修正：** 先檢查 `name == "q"`，再讀取和轉換金幣。

### ❌ 把一個角色的資料直接加入成文字

```python
characters.append(name)
```

這樣只保存名字，之後沒有對應的金幣。

**✅ 修正：** 把角色名稱和金幣一起放進 Dictionary。

```python
characters.append({"name": name, "gold": gold})
```

### ❌ 空 List 也計算平均值

```python
average_gold = total_gold / len(characters)
```

若一開始就輸入 `q`，`characters` 是空的，`len(characters)` 是 0，不能作除數。

**✅ 修正：** 先判斷 `len(characters) == 0`，沒有資料時只顯示提示。
