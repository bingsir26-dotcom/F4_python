## 新概念

### 1. 作品先拆成小任務

不要一開始寫一大段程式。先把任務分開：

1. 用 List 保存多位學生的資料；
2. 用 Dictionary 保存一位學生的姓名和分數；
3. 用 `while` 重複收集資料；
4. 用函式決定成績等級；
5. 用 `for` 顯示每一位學生並計算平均。

### 2. 測試不是最後才做

至少準備三種資料：

- **正常情況**：例如 75、88；
- **邊界情況**：例如 59、60、79、80、89、90；
- **特別情況**：一開始就輸入 `q`，沒有學生資料。

## 跟著做：例子 1——收集學生資料

```python
students = []

while True:
    name = input("學生姓名（輸入 q 結束）：").strip()

    if name == "q":
        break

    score = int(input("分數："))
    student = {"name": name, "score": score}
    students.append(student)

print(students)
```

### 預期輸出／結果

```text
學生姓名（輸入 q 結束）：小美
分數：80
學生姓名（輸入 q 結束）：小強
分數：65
學生姓名（輸入 q 結束）：q
[{'name': '小美', 'score': 80}, {'name': '小強', 'score': 65}]
```

### 逐行解釋

```python
student = {"name": name, "score": score}
```

每位學生有兩項有名稱的資料：`name` 和 `score`，因此用一個 Dictionary 保存。

```python
students.append(student)
```

`students` 是 List；每輸入一位學生，就把他的 Dictionary 加進 List。於是它能保存多筆資料。

## 再試一次：例子 2——顯示等級和平均分

把以下函式和程式加在例子 1 的最後：

```python
def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 60:
        return "C"
    return "F"

if len(students) > 0:
    total = 0

    for student in students:
        score = student["score"]
        total = total + score
        print(f"{student['name']}：{score} 分，{get_grade(score)}")

    print(f"平均分：{total / len(students):.1f}")
else:
    print("沒有輸入學生資料。")
```

### 這次加入了甚麼？

- `get_grade()` 把「根據分數決定等級」的工作收好；
- `student["score"]` 取出每位學生的分數；
- 先檢查 `len(students) > 0`，才計算平均，避免除以 0；
- `:.1f` 令平均分只顯示 1 位小數。

## 易錯位

### ❌ 先把 `q` 轉成分數

```python
score = int(input("分數："))
if name == "q":
    break
```

如果已輸入 `q`，程式根本不應再問分數。

**✅ 修正：** 先檢查 `name == "q"`，再讀取和轉換分數。

### ❌ 把一位學生的資料直接加入成文字

```python
students.append(name)
```

這樣只保存名字，之後沒有對應的分數。

**✅ 修正：** 先建立 `{"name": name, "score": score}`，再加入 List。

### ❌ 空 List 也計算平均

```python
print(total / len(students))
```

沒有學生時，`len(students)` 是 0，不能作除數。

**✅ 修正：** 先用 `if len(students) > 0:` 保護。
