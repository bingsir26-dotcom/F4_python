# 第 9 課：函式——把重複工作收好

> **本課主題：把一段會重複使用的程式碼取一個名字，需要時再呼叫它。**
>
> 寫遊戲、整理資料、訓練模型時，同一種工作往往要做很多次。函式可以讓程式更短、更清楚，也較容易修改。

## 今課可以做到甚麼？

完成這一課後，你可以：

- 把重複的程式步驟寫成自己的函式；
- 把不同資料交給同一個函式處理；
- 讓函式算出結果，再交回主程式使用。

## 開始前：想一想

你想在遊戲開始、玩家過關、遊戲結束時都顯示一條橫線和一句訊息。直接複製貼上當然可以：

```python
print("=" * 20)
print("遊戲開始")
print("=" * 20)
```

但當你想把橫線由 20 個 `=` 改成 30 個時，要找回每一段重複程式逐一修改。能否只寫一次，然後給這個工作一個名字？

## 新概念

### 1. 函式：一個可重複使用的小工具

函式（function）是一段有名字的程式。你先**定義**它，之後再用它的名字**呼叫**它。

```python
def show_line():
    print("=" * 20)

show_line()
show_line()
```

![函式由名稱、括號與縮排的工作內容組成；呼叫同一函式可重複執行](/images/lesson-09-functions.svg)

`def` 是 Python 的關鍵字，表示「現在要定義函式」。`show_line` 是你替這個工具取的名字。函式內的程式碼要向右縮排四個空格；這表示它們屬於這個函式。

只有寫出 `def show_line():` 還不會顯示任何東西；寫出 `show_line()` 時，Python 才會執行函式內的程式。

### 2. 參數：把不同資料交給函式

如果每次要顯示的訊息不同，可在括號內放一個參數（parameter）。參數像函式暫時使用的變數。

```python
def welcome(name):
    print(f"歡迎你，{name}！")

welcome("Alex")
welcome("May")
```

第一次呼叫時，`name` 是 `"Alex"`；第二次呼叫時，`name` 是 `"May"`。同一個工具可以處理不同資料。

### 3. `return`：把答案交回去

有些函式不只顯示內容，而是負責算答案。`return` 會把答案交回呼叫它的地方。

```python
def calculate_average(score_1, score_2):
    return (score_1 + score_2) / 2

average = calculate_average(78, 92)
print(average)
```

`calculate_average(78, 92)` 的結果是 `85.0`，所以它可以放在指定變數、`print()` 或其他計算式中使用。

## 跟著做：例子 1——重複使用的歡迎訊息

```python
def welcome_player(player_name):
    print("=" * 20)
    print(f"歡迎你，{player_name}！")
    print("準備開始冒險。")

welcome_player("Alex")
welcome_player("May")
```

### 預期輸出

```text
====================
歡迎你，Alex！
準備開始冒險。
====================
歡迎你，May！
準備開始冒險。
```

### 逐行解釋

```python
def welcome_player(player_name):
```

定義一個名為 `welcome_player` 的函式；它需要一份資料，暫時叫作 `player_name`。

```python
    print(f"歡迎你，{player_name}！")
```

這一行有縮排，所以是函式的一部分。f-string 會把每次收到的玩家名稱放進訊息中。

```python
welcome_player("Alex")
```

呼叫函式，把 `"Alex"` 交給 `player_name`。接著第二次呼叫，只改傳入的名稱。

## 再試一次：例子 2——把平均分交回主程式

```python
def calculate_average(score_1, score_2, score_3):
    total = score_1 + score_2 + score_3
    return total / 3

math_average = calculate_average(78, 91, 84)
science_average = calculate_average(82, 76, 89)

print(f"數學小組平均分：{math_average}")
print(f"科學小組平均分：{science_average}")
```

### 預期輸出

```text
數學小組平均分：84.33333333333333
科學小組平均分：82.33333333333333
```

要令輸出較整齊，可以把最後兩行改成：

```python
print(f"數學小組平均分：{math_average:.1f}")
print(f"科學小組平均分：{science_average:.1f}")
```

`.1f` 表示保留一位小數。

## 易錯位

### ❌ 函式內容沒有縮排

```python
def welcome(name):
print(f"你好，{name}")
```

**原因：** Python 看不出哪一行屬於 `welcome`。

**✅ 修正：** 函式內容統一向右縮排四個空格。

```python
def welcome(name):
    print(f"你好，{name}")
```

### ❌ 只定義，忘記呼叫

```python
def show_score():
    print(80)
```

這段程式不會輸出內容，因為還未要求 Python 執行函式。

**✅ 修正：**

```python
show_score()
```

### ❌ 呼叫時少了需要的資料

```python
def welcome(name):
    print(name)

welcome()
```

**原因：** 函式需要 `name`，但呼叫時沒有交資料給它。

**✅ 修正：**

```python
welcome("Alex")
```

### ❌ 把 `print()` 當成 `return`

```python
def calculate_total(price_1, price_2):
    print(price_1 + price_2)

answer = calculate_total(20, 30)
print(answer)
```

`print()` 只是顯示 `50`，沒有把 `50` 交回 `answer`；最後會顯示 `None`。

**✅ 修正：** 當其他地方還要使用答案時，改用 `return`。

```python
def calculate_total(price_1, price_2):
    return price_1 + price_2
```

## 本課小結

1. `def` 用來定義函式；只有呼叫 `函式名稱()` 時，函式內的程式才會執行。
2. 參數讓同一個函式可以處理不同資料。
3. `return` 把計算結果交回主程式，讓答案可以繼續使用。
