## 新概念

### 1. 分類的標籤是類別

二元分類只有兩類，例如 `0／1`、`否／是`；多分類則有三類或以上，例如三種花、三種動物。數字標籤只是方便電腦處理，不代表 2 比 1 更好。

### 2. 決策邊界

分類模型會在特徵空間中找出大致的分界。邊界附近的資料通常較難判斷，也最需要測試。

## 跟著做：例子 1——以練習時間分類是否及格

```python
from sklearn.neighbors import KNeighborsClassifier

# [每天練習小時]，0 = 未及格，1 = 及格
hours = [[0.5], [1.0], [1.5], [2.0], [2.5], [3.0]]
passed = [0, 0, 0, 1, 1, 1]

model = KNeighborsClassifier(n_neighbors=3)
model.fit(hours, passed)

result = model.predict([[1.8]])
print(result)
```

### 預期輸出／結果

輸出 `[1]` 代表模型把 1.8 小時這筆資料分類為「及格」。

### 逐行解釋

`KNeighborsClassifier` 會看新資料附近的已知例子。`n_neighbors=3` 表示它會參考最接近的三筆資料，再以多數類別作判斷。

## 再試一次：例子 2——把數字標籤變成可讀訊息

```python
if result[0] == 1:
    print("模型預測：及格")
else:
    print("模型預測：未及格")
```

`result` 是一個包含預測結果的 List-like 陣列。`result[0]` 取出第一筆結果，再以 `if` 顯示人看得懂的文字。

## 易錯位

### ❌ 把分類結果當作評語

模型輸出「未及格」只代表它根據訓練資料的預測，不應用作對人的固定標籤或自動作出高風險決定。

### ❌ 類別資料不平衡卻只看準確率

若 95% 資料都是同一類，模型全部猜該類也有 95% 準確率；之後需要看更完整的評估方式。

## 本課小結

1. 分類的答案是類別，迴歸的答案是連續數值。
2. KNN 可根據附近已知例子判斷新資料的類別。
3. 邊界附近和資料不平衡情況都要小心評估。
