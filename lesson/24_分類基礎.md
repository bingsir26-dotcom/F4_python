# 第 24 課：分類基礎——讓模型選一個類別

> **本課主題：當答案不是一個數字，而是幾個選項之一時，讓模型從已知例子中選出較合適的類別。**
>
> 上一課的房價預測會回答「大約多少」。這一課的答案改成「是哪一類」：例如根據氣溫，在「長袖」和「短袖」兩個建議中選一個。

## 今課可以做到甚麼？

- 分辨預測數字的迴歸和選擇類別的分類；
- 用虛構資料讓模型作出一個簡單的服裝建議；
- 看懂分類模型輸出的文字類別。

## 開始前：想一想

如果今天是 13°C，你可能會選長袖；若是 30°C，你大概會選短袖。

假設我們收集了幾天的「氣溫＋服裝建議」資料，能否由附近的已知天氣，為 20.5°C 給出一個簡單建議？

這不是要模型替人決定穿甚麼，而是用一個低風險例子理解：**答案可以是類別，而不是數字。**

## 新概念

### 1. 分類是在選類別

- **迴歸**：答案是數字，例如房價、氣溫、售出數量；
- **分類**：答案是類別，例如「長袖／短袖」、「貓／狗」、「正常／故障」。

電腦可以用文字或數字保存類別。若使用 `0` 和 `1`，它們只是代號，不代表其中一類較好。

### 2. KNN：參考附近的已知例子

這一課使用 `KNeighborsClassifier`。它的基本想法很直觀：新資料出現時，先找出最接近的幾筆已知資料，再以當中較多的類別作出判斷。

![分類先看已有類別，再為一筆新資料選出其中一類](/images/lesson-24-classification-basics.svg)

`n_neighbors=3` 的意思是：參考最接近的三筆資料。現在不用計算距離公式，先看懂它在「看附近例子」。

## 跟著做：例子 1——按氣溫分類服裝建議

```python
from sklearn.neighbors import KNeighborsClassifier

# 每一筆輸入是 [氣溫（°C）]；答案是課堂用的簡化服裝建議
temperatures = [[12], [15], [20], [22], [23], [31]]
outfits = ["長袖", "長袖", "長袖", "短袖", "短袖", "短袖"]

model = KNeighborsClassifier(n_neighbors=3)
model.fit(temperatures, outfits)

prediction = model.predict([[20.5]])
print("20.5°C 的模型建議：", prediction[0])
```

### 預期輸出／結果

```text
20.5°C 的模型建議： 短袖
```

### 逐行解釋

```python
temperatures = [[12], [15], [20], [22], [23], [31]]
```

這是六筆輸入資料，每筆只有一個特徵：氣溫。

```python
outfits = ["長袖", "長袖", "長袖", "短袖", "短袖", "短袖"]
```

這是每筆資料對應的類別。第一個「長袖」對應 12°C，第四個「短袖」對應 22°C。

```python
model = KNeighborsClassifier(n_neighbors=3)
```

建立分類模型，並設定它參考最接近的三筆已知資料。

```python
prediction = model.predict([[20.5]])
```

請模型為 20.5°C 選出一個類別。`prediction` 內可能有多筆結果；`prediction[0]` 取出第一筆，方便直接顯示。

## 再試一次：例子 2——改變「參考附近幾筆」的數量

這一段也是**可獨立執行**。它把 `n_neighbors` 改成 1：模型只參考最接近的一筆資料。比較結果是否和例子 1 相同？

```python
from sklearn.neighbors import KNeighborsClassifier

temperatures = [[12], [15], [20], [22], [23], [31]]
outfits = ["長袖", "長袖", "長袖", "短袖", "短袖", "短袖"]

model = KNeighborsClassifier(n_neighbors=1)
model.fit(temperatures, outfits)

prediction = model.predict([[20.5]])
print("20.5°C 的模型建議：", prediction[0])
```

在這組資料中，20.5°C 最接近 20°C，所以結果會是「長袖」。和例子 1 的「短袖」不同，正好提醒我們：模型設定和訓練資料都會影響輸出。

## 易錯位

### ❌ 把分類結果當成對人的固定評語

分類模型只會根據它看過的資料作出判斷。它不應用來替人貼標籤，或自動處理會嚴重影響人的決定。

### ❌ 輸入格式和訓練時不同

```python
model.predict([20.5])
```

**原因：** 訓練時每筆資料都寫成 `[氣溫]`；預測一筆新資料時，仍要保留「一筆資料」那一層。

**✅ 修正：**

```python
model.predict([[20.5]])
```

### ❌ 以為輸出是唯一正確答案

真實服裝選擇還與濕度、風力、個人感受有關。這個範例只有一個特徵，只用來理解分類流程。

## 本課小結

1. 分類的答案是類別；迴歸的答案是連續數字。
2. KNN 會參考附近的已知例子來判斷新資料。
3. 資料和 `n_neighbors` 設定都可能改變分類結果。
