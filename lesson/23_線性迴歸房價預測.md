## 開始前：想一想

兩間面積相同的房屋，價格一定一樣嗎？地點、樓層、裝修都會影響價格。即使如此，面積資料是否仍可提供一個大致估計？

## 新概念

### 1. 迴歸回答「大約是多少」

當答案是價格、溫度、時間或分數等連續數字時，常用**迴歸（regression）**。線性迴歸假設特徵和答案之間可先用一條直線近似。

### 2. 預測值不等於真實值

直線描述整體趨勢；每個真實資料點可能在直線上方或下方。兩者的差距叫作誤差，之後會用它評估模型。

![線性迴歸的核心概念：面積、價格、趨勢線、預測](/images/lesson-23-linear-regression.svg)

## 跟著做：例子 1——由面積估計房價

```python
from sklearn.linear_model import LinearRegression

areas = [[30], [45], [60], [75], [90]]
prices = [320, 430, 540, 650, 760]  # 單位：萬

model = LinearRegression()
model.fit(areas, prices)

price_70 = model.predict([[70]])
print(price_70)
```

### 預期輸出／結果

模型會輸出一個接近 `600` 的預測房價（萬）。確實數值會由訓練資料決定。

### 逐行解釋

`areas` 的每一項是房屋面積，`prices` 是對應房價。線性迴歸找到兩者的整體關係，再估計 70 平方米房屋的價格。

## 再試一次：例子 2——把資料和趨勢線畫出來

```python
import matplotlib.pyplot as plt

plt.scatter([30, 45, 60, 75, 90], prices, label="真實資料")
plt.plot([30, 45, 60, 75, 90], model.predict(areas), color="red", label="模型趨勢")
plt.xlabel("面積")
plt.ylabel("房價（萬）")
plt.legend()
plt.show()
```

`scatter()` 顯示真實資料點；`plot()` 畫出模型在已知面積上的預測線。看見紅線不代表每一點都要剛好在紅線上。

## 易錯位

### ❌ 只用一個重要性不足的特徵就下結論

面積可作初步示範，但真實房價還受地點、屋齡、交通等影響。模型沒有看見的因素不會自動被考慮。

### ❌ 圖表的 x 和 y 用錯

面積是輸入特徵，應放在 x 軸；房價是想預測的答案，通常放在 y 軸。
