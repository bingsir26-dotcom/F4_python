# 第 23 課：線性迴歸——由面積估計房價

> **本課主題：當答案是「大約多少」這種連續數字時，用線性迴歸找出資料的整體趨勢。**
>
> 房屋面積較大，價格往往也較高；但真實房價還會受地點、屋齡和交通等影響。這一課只用虛構資料，學習如何由一個因素作出初步估計。

## 今課可以做到甚麼？

- 分辨「預測數字」的迴歸問題和「選類別」的分類問題；
- 用房屋面積資料估計新房屋的大約價格；
- 畫出資料點和模型趨勢線，理解預測不是精確答案。

## 開始前：想一想

兩間都是 70 平方米的房屋，價格一定一樣嗎？

不一定。附近設施、樓齡、裝修、景觀等都可能令價格不同。不過，若只有面積和幾筆歷史價格，能否先做出一個有根據的估計？

## 新概念

### 1. 迴歸回答「大約是多少」

當答案是價格、溫度、時間、距離等**連續數字**，這類問題稱為**迴歸**（regression）。

第 22 課的氣溫和雪糕數量也是迴歸：答案不是固定類別，而是一個可大可小的數字。

### 2. 線性迴歸找整體趨勢

線性迴歸會用一條直線概括資料的整體走向。資料點不必全部落在直線上；直線只是在目前資料下作出的最佳近似。

![房屋面積和價格的資料點、整體趨勢線，以及一筆新資料的預測](/images/lesson-23-linear-regression.svg)

## 跟著做：例子 1——由面積估計房價

```python
from sklearn.linear_model import LinearRegression

# 每一筆輸入是 [面積（平方米）]；答案是房價（萬）
areas = [[30], [45], [60], [75], [90]]
prices = [310, 420, 570, 640, 790]

model = LinearRegression()
model.fit(areas, prices)

price_70 = model.predict([[70]])
print(price_70)
```

### 預期輸出／結果

畫面會顯示一個接近 `620` 的數字（萬）。它是根據這五筆虛構資料的估計，不是 70 平方米房屋的真正市價。

### 逐行解釋

```python
areas = [[30], [45], [60], [75], [90]]
```

這是模型的輸入資料。每間房屋目前只有一個特徵——面積。

```python
prices = [310, 420, 570, 640, 790]
```

這是每間房屋的已知價格。第一個 310 對應第一間 30 平方米房屋。

```python
model.fit(areas, prices)
```

讓線性迴歸模型從「面積」和「價格」的對應關係找出整體趨勢。

```python
price_70 = model.predict([[70]])
```

請模型估計一間 70 平方米房屋的價格。輸入格式仍是 `[[70]]`：一筆資料，內有一個特徵。

## 再試一次：例子 2——把資料和趨勢線畫出來

**先執行例子 1**，再執行以下程式。這樣 `areas`、`prices` 和已完成訓練的 `model` 都已準備好。

```python
import matplotlib.pyplot as plt

area_numbers = [30, 45, 60, 75, 90]
trend_prices = model.predict(areas)

plt.scatter(area_numbers, prices, label="已知房屋")
plt.plot(area_numbers, trend_prices, color="red", label="模型趨勢")
plt.xlabel("面積（平方米）")
plt.ylabel("房價（萬）")
plt.legend()
plt.show()
```

- `scatter()` 畫出每一間已知房屋的資料點；
- `model.predict(areas)` 計算這些面積在趨勢線上的預測值；
- `plot()` 把這些預測值連成紅色趨勢線。

有些點在紅線上方，有些在下方，正好表示真實資料不會完全一樣。

## 易錯位

### ❌ 以為預測值就是實際房價

面積只是其中一個因素。模型沒有看見地點、屋齡、樓層等資料，就不能把它們計算進去。

**✅ 正確理解：** 這是基於有限資料的初步估計，應配合更多資料和人作判斷。

### ❌ 把 x 軸和 y 軸的角色放反

面積是輸入特徵，通常放在 x 軸；房價是想估計的答案，通常放在 y 軸。

### ❌ 忘記 `fit()` 就直接 `predict()`

```python
model = LinearRegression()
print(model.predict([[70]]))
```

**原因：** 模型尚未從任何例子學到規律。

**✅ 修正：** 先執行 `model.fit(areas, prices)`。
