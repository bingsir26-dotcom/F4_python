## 使用方式

- 直接修改 Markdown 課程內容。
- 教學圖片放在 `public/images`，在 Markdown 內以 `/images/檔名.svg` 引用。
- 範例資料放在 `public/data`；學生要在 Jupyter／Colab 執行時，需先下載或上傳 CSV 到自己的工作資料夾。
- 網站導覽在 `.vitepress/config.mts` 設定；新增或重新排列課程時，要同步更新這裡和本清單。
- 原始 Word 文件保留在課程根目錄，沒有被修改。
