## 新概念

### 1. 甚麼是程式？

程式（program）就是一組有次序的指令，用來告訴電腦應該做甚麼。

例如，「煮一杯熱朱古力」可以拆成：

1. 準備杯子。
2. 放入朱古力粉。
3. 加入熱水。
4. 攪拌。
5. 試味道。

電腦不會像人一樣「大概明白」，所以步驟要清楚，而且次序要正確。

### 2. 甚麼是程式語言？

程式語言是人和電腦溝通時使用的規則和文字。

常見的程式語言包括：

- Python：適合初學、資料分析、人工智能及自動化工作；
- JavaScript：常用於網頁互動；
- Java、C++：常見於大型系統、應用程式或需要高效能的程式。

這一科先學 Python，因為它的基本語法相對容易閱讀，而且可以逐步連接到很多不同方向。

### 3. 學 Python 現在可以做甚麼？

Python 不是只有用來做數學題，也不是只給專業程式員使用。它可以用來：

| 方向 | 可以做的事情 | 在課堂中可以怎樣體驗 |
|---|---|---|
| 自動化 | 重複處理檔案、計算資料、整理文字 | 自動計算全班成績 |
| 網頁與服務 | 製作網站的後端功能、資料服務 | 了解一個網站背後怎樣處理資料 |
| 資料分析 | 整理表格、找規律、比較數據 | 分析班級成績或問卷結果 |
| 人工智能 | 使用資料訓練或呼叫 AI 模型 | 了解 AI 如何處理文字、圖片和數字 |
| 遊戲與模擬 | 猜數字、隨機抽籤、模擬規則 | 製作自己的小遊戲 |
| 科學與工程 | 計算、模擬、處理感測器資料 | 觀察溫度或運動資料的變化 |

這裡的重點不是現在就學會所有方向，而是先建立「我可以用程式解決問題」的信心。

### 4. Python 和人工智能有甚麼關係？

人工智能（AI）可以理解為：讓電腦根據資料和規則，完成一些通常需要人來判斷的工作，例如辨認圖片、理解文字或預測結果。

Python 常常出現在 AI 的學習和開發流程中，因為它有很多處理資料、數學運算和模型的工具。

但要注意：

> **會寫幾行 Python，不等於已經懂人工智能。**

學 Python 是打好地基。之後還需要學習：

- 怎樣取得和整理資料；
- 怎樣判斷資料是否可靠；
- 怎樣用數學方法找出規律；
- 怎樣測試結果是否合理；
- 怎樣負責任地使用人工智能。

### 5. Python 和資料分析有甚麼關係？

資料分析就是從一堆資料中找出有用的資訊，並用證據回答問題。

例如，不只是問「哪班成績好」，而是問：

- 哪一科平均分最高？
- 哪一班的分數差距較大？
- 有多少人及格？
- 成績是否隨測驗次數進步？
- 圖表是否真的支持我們的結論？

日後我們會用 Python 逐步完成這條流程：

```text
提出問題
  ↓
收集資料
  ↓
整理資料
  ↓
計算與比較
  ↓
製作圖表
  ↓
用文字解釋結果
```

### 6. 行業現況：為甚麼這些能力值得學？

現在很多工作都不一定要求每個人都成為專業程式員，但愈來愈多工作需要：

- 使用數碼工具；
- 看懂表格和圖表；
- 處理大量資料；
- 自動化重複工作；
- 與人工智能工具合作；
- 判斷電腦產生的結果是否合理。

因此，學 Python 的價值不只是「將來做程式員」，也包括培養以下能力：

1. **拆解問題**：把大問題分成小步驟。
2. **邏輯思考**：清楚說明每一步為甚麼這樣做。
3. **資料素養**：不只看答案，也檢查資料和證據。
4. **創作能力**：把想法變成可以運作的作品。
5. **持續學習**：遇到錯誤時，懂得閱讀提示、查找原因和修改。

::: warning 不要把 Python 當成保證成功的捷徑
學會 Python 不會自動保證將來取得某一份工作。真正重要的是，你能否用它解決問題、解釋想法、驗證結果，並持續學習新工具。
:::

## 跟著做：例子 1——讓電腦介紹自己

先不要急著寫複雜程式。我們先讓電腦按指定次序顯示幾句話。

```python
print("大家好，我正在學 Python！")
print("我可以用程式解決問題。")
print("第一個目標：做一個小作品。")
```

### 預期輸出

```text
大家好，我正在學 Python！
我可以用程式解決問題。
第一個目標：做一個小作品。
```

### 逐行解釋

```python
print("大家好，我正在學 Python！")
```

- `print` 是 Python 用來顯示內容的指令。
- `()` 表示我們把要顯示的內容交給 `print`。
- 引號內是文字，文字可以改成你自己的句子。

```python
print("我可以用程式解決問題。")
```

電腦會按照程式碼由上到下執行，所以這句會在第一句之後顯示。

## 再試一次：例子 2——改變程式的工作

只修改引號內的一句話，觀察輸出如何改變：

```python
print("我想用 Python 製作一個猜數字遊戲。")
print("我想用 Python 分析運動數據。")
print("我想用 Python 製作自己的小工具。")
```

### 先想一想

- 如果把第二行和第三行交換，輸出會怎樣？
- 如果刪除第一行，電腦會顯示甚麼？
- 如果忘記一個引號，程式會否仍然正常執行？

::: details 教師提示
這裡不要急著解釋所有錯誤訊息。先讓學生知道「錯誤是電腦告訴我們需要修改的地方」，並請學生比較正確和錯誤版本。
:::

## 易錯位

### 錯誤一：把文字寫在沒有引號的位置

```python
print(我正在學 Python)
```

Python 會把沒有引號的內容當成其他名稱，通常會產生錯誤。

修正：

```python
print("我正在學 Python")
```

### 錯誤二：括號沒有成對

```python
print("Hello"
```

修正：

```python
print("Hello")
```

### 錯誤三：把 `print` 寫成其他拼法

```python
Print("Hello")
```

Python 會分辨大小寫，`Print` 和 `print` 不一樣。

### 錯誤四：只看錯誤最後一行就放棄

看到錯誤時，先做三件事：

1. 找出錯誤訊息最後指出的行數；
2. 檢查括號、引號和拼字；
3. 一次只修改一個地方，再重新執行。

## 本課小結
