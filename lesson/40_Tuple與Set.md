# 第 40 課：Tuple 與 Set——固定資料和不重複清單

> **本課主題：遇到「資料不應改動」或「只想保留不同項目」時，選擇比 List 更合適的資料結構。**
>
> List 已能完成很多工作。Tuple 和 Set 是補充工具：知道它們各自解決甚麼問題，比硬背所有方法更重要。

## 今課可以做到甚麼？

- 用 Tuple 保存一組固定的座標或設定；
- 用 Set 從重複紀錄中找出不同項目；
- 說出為甚麼 Set 不能用索引取「第一項」。

## 開始前：想一想

班級興趣調查收到：`籃球、音樂、籃球、編程、音樂`。如果只想知道班上有哪幾種不同興趣，要怎樣自動刪除重複？

另一邊，一個地圖座標 `(3, 5)` 是兩個配對的數字。程式不小心改了其中一個，會不會令位置資料變得不可靠？

## 新概念

### 1. Tuple：一組固定位置的資料

Tuple 寫成 `(3, 5)`。它有順序，所以可以用索引讀取；但建立後不能直接改寫內容。座標、RGB 顏色、日期這類「一組固定資料」很適合使用 Tuple。

### 2. Set：只保留不同的項目

Set 寫成 `{"籃球", "音樂"}`。它會自動移除重複值，適合回答「有幾種？」、「兩組共同有甚麼？」這類問題。

Set **沒有固定順序**，因此不能寫 `hobbies[0]`。若只是為了展示結果，可用 `sorted(hobbies)` 排成穩定順序。

![Tuple 保存固定座標；Set 由重複興趣中保留不同項目](/images/lesson-40-tuple-set.svg)

## 跟著做：例子 1——保存角色出生位置

```python
spawn_point = (3, 5)

print("x 座標：", spawn_point[0])
print("y 座標：", spawn_point[1])

x, y = spawn_point
print(f"角色由 ({x}, {y}) 出發")
```

### 預期輸出

```text
x 座標： 3
y 座標： 5
角色由 (3, 5) 出發
```

### 逐行解釋

`spawn_point` 保存兩個按順序排列的數字。索引 `0` 代表第一個位置、索引 `1` 代表第二個位置。

`x, y = spawn_point` 稱為**拆包**：把 Tuple 內兩個值，依序放進兩個變數。這不會改變原本的 Tuple。

## 再試一次：例子 2——找出不同興趣

```python
responses = ["籃球", "音樂", "籃球", "編程", "音樂"]
hobbies = set(responses)

print("不同興趣：", sorted(hobbies))
print("種類數目：", len(hobbies))
```

### 預期輸出

```text
不同興趣： ['編程', '籃球', '音樂']
種類數目： 3
```

`set(responses)` 建立 Set 時已經去除重複值。`sorted()` 只是為了讓顯示次序穩定；Set 本身不保證排列次序。

## 易錯位

### ❌ 以為 Tuple 可以直接改其中一項

```python
# spawn_point[0] = 8
```

**原因：** Tuple 的內容固定，這行會出現錯誤。

**✅ 修正：** 要新位置便建立新的 Tuple，例如 `spawn_point = (8, 5)`。

### ❌ 用索引讀取 Set

```python
# hobbies[0]
```

**原因：** Set 沒有「第一項」的概念。

**✅ 修正：** 用 `for hobby in hobbies:` 逐項處理；要穩定展示可用 `sorted(hobbies)`。

### ❌ 忘記空 Set 的寫法

`{}` 是空 Dictionary，不是空 Set。

**✅ 修正：** 寫 `set()` 建立空 Set。

## 本課小結

1. Tuple 適合保存固定、有順序的一組資料。
2. Set 自動移除重複值，適合處理「不同項目」的問題。
3. Set 沒有固定順序，不能用索引讀取。
