## 開始前：想一想

兩班的平均分同樣是 75 分，是否代表兩班表現完全一樣？

| 班別 | 分數 |
|---|---|
| A | 75、75、75 |
| B | 50、75、100 |

平均一樣，但 B 班的分數差距很大。所以資料分析不只看一個數字，也要知道自己正在回答甚麼問題。

### 先猜一猜

下面哪一個最適合回答「全班通常考幾多分？」

```python
scores_df["數學"].max()
scores_df["數學"].mean()
scores_df["數學"].min()
```

一般情況下是 `mean()`，即平均值。但它不能告訴你所有細節，所以之後還會看最高、最低和分組結果。

## 新概念

### 1. 四個常用統計數字

```python
scores_df["數學"].mean()    # 平均值
scores_df["數學"].max()     # 最高值
scores_df["數學"].min()     # 最低值
scores_df["數學"].median()  # 中位數
```

- **平均值**：把全部數值加起來再除以數量。
- **最高值／最低值**：最快找出範圍。
- **中位數**：把數字由小到大排好後，位於中間的數值；極端高分或低分較多時，它有時比平均值更能代表「中間情況」。

### 2. `describe()`：快速概覽

```python
print(scores_df[["數學", "英文"]].describe())
```

`describe()` 一次顯示多個統計結果。第一天不必背每一列的意思；先學會看 `count`、`mean`、`min` 和 `max`。

### 3. `groupby()`：按類別比較

```python
scores_df.groupby("班別")["數學"].mean()
```

可以讀成：

```text
先按「班別」分組，然後各組計算「數學」平均值。
```

## 跟著做：例子 1——先看全班數學表現

```python
import pandas as pd

student_data = {
    "姓名": ["Alex", "Chris", "May", "Sam", "Lily", "Ken"],
    "班別": ["F4A", "F4A", "F4B", "F4B", "F4A", "F4B"],
    "數學": [78, 65, 91, 72, 84, 60],
    "英文": [82, 70, 88, 69, 90, 74]
}

scores_df = pd.DataFrame(student_data)

print(scores_df["數學"].mean())
print(scores_df["數學"].max())
print(scores_df["數學"].min())
```

### 預期輸出

```text
75.0
91
60
```

### 逐行解釋

```python
scores_df["數學"]
```

先選出數學這一欄。

```python
.mean()
```

再對這一欄計算平均值。`max()` 和 `min()` 的寫法相同，只是問不同問題。

## 再試一次：例子 2——比較兩班數學平均分

```python
class_math_mean = scores_df.groupby("班別")["數學"].mean()
print(class_math_mean)
```

### 預期輸出

```text
班別
F4A    75.666667

Name: 數學, dtype: float64
```

這次不是計算全班一個平均值，而是分成 F4A、F4B 後各算一次平均。

## 易錯位

### ❌ 對整張表直接取平均

```python
scores_df.mean()
```

**問題：** DataFrame 同時有文字欄和數字欄時，在目前 pandas 版本這行可能直接出錯；即使某個環境能執行，也未必是你真正想平均的資料。

**✅ 先選清楚欄位：**

```python
scores_df["數學"].mean()
```

### ❌ 分組欄名和計算欄名寫反

```python
scores_df.groupby("數學")["班別"].mean()
```

**問題：** 班別是文字，不能計算平均；而且這不是我們想問的問題。

**✅ 修正：**

```python
scores_df.groupby("班別")["數學"].mean()
```

### ❌ 把平均分當成所有學生的完整故事

平均分可以快速比較，但不能告訴你每位學生的情況。回答問題前，先說清楚你想比較的是全班、某一班，還是個別學生。
