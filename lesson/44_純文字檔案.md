## 新概念

### 1. 純文字檔是甚麼？

`.txt` 檔案只保存文字，例如筆記、日誌、每行一個名字的名單。它不像 CSV 特別用逗號分欄，也不像 JSON 有固定結構；因此很適合先練習最基本的檔案讀寫。

### 2. 三個常用動作

- `write_text()`：建立或覆寫整個檔案；
- `read_text()`：一次讀取整個檔案；
- `splitlines()`：把文字按每一行拆成 List。

範例使用 `encoding="utf-8"`，讓中文可以正確保存和讀取。

## 跟著做：例子 1——建立並讀回待辦清單

```python
from pathlib import Path

file_path = Path("todo.txt")
content = "完成功課\n溫習 Python\n準備明天的書本\n"

file_path.write_text(content, encoding="utf-8")
text = file_path.read_text(encoding="utf-8")
print(text)
```

### 預期輸出／結果

```text
完成功課
溫習 Python
準備明天的書本
```

### 逐行解釋

`Path("todo.txt")` 代表與目前程式同一資料夾內的檔案。`write_text()` 會建立檔案；若檔案已存在，內容會被新的文字取代。然後 `read_text()` 讀回整段內容。

## 再試一次：例子 2——逐行統計完成項目

```python
from pathlib import Path

file_path = Path("todo.txt")
lines = file_path.read_text(encoding="utf-8").splitlines()

for number, item in enumerate(lines, start=1):
    print(f"{number}. {item}")

print("項目數量：", len(lines))
```

### 這次改了甚麼？

`splitlines()` 把每一行拆開，`enumerate(..., start=1)` 同時提供項目編號和內容。這段程式假設例子 1 已建立 `todo.txt`；若獨立執行，先執行例子 1 或自行建立同名檔案。

## 易錯位

### ❌ 把路徑或檔名打錯

**原因：** 找不到檔案時會出現 `FileNotFoundError`。

**修正方法：** 先確認檔案是否在程式同一資料夾，或顯示 `file_path.resolve()` 查看完整位置。

### ❌ 用 `write_text()` 以為會在舊內容後面加入文字

**原因：** 它會覆寫原有內容。

**修正方法：** 要保留舊資料時，先讀出內容並合併，或之後再學習附加模式。

### ❌ 沒有指定 UTF-8 編碼

**原因：** 不同電腦的預設編碼可能不同，中文容易變成亂碼。

**修正方法：** 讀寫中文檔案時明確使用 `encoding="utf-8"`。
