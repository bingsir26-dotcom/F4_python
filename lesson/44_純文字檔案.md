# 第 44 課：純文字檔案——讓程式把資料保存下來

>
> 變數只在程式運行期間存在。程式結束後仍要保留的備忘、日誌或名單，可以先使用最簡單的文字檔案。

- 讀回文字檔的全部內容或逐行內容；

## 開始前：想一想

你做了一個讀書紀錄程式，今天輸入的內容在關閉程式後消失。明天重新開啟時，程式怎樣才能記得昨天已讀的書？

## 新概念

### 1. 檔案是程式以外的保存空間

`open()` 讓程式開啟檔案；`with` 區塊結束時會自動關閉檔案，即使中間發生錯誤也較安全。中文文字檔應指定 `encoding="utf-8"`。

### 2. 寫入模式和追加模式

- `"w"`：重新寫入檔案；原有內容會被覆蓋；
- `"a"`：把新內容加在檔案最後；
- `"r"`：讀取檔案。

![程式建立讀書紀錄文字檔；寫入三行；再次開啟並逐行讀回](/images/lesson-44-text-files.svg)

## 跟著做：例子 1——建立讀書紀錄檔

```python
notes = ["閱讀：Python 變數", "練習：for 迴圈", "問題：甚麼時候用 List？"]

with open("study_notes.txt", "w", encoding="utf-8") as file:
    for note in notes:
        file.write(note + "\n")

print("已建立 study_notes.txt")
```

### 預期輸出／結果

```text
已建立 study_notes.txt
```

程式所在資料夾會出現 `study_notes.txt`，內容有三行紀錄。

### 逐行解釋

`with open(...) as file` 把開啟的檔案暫時命名為 `file`。模式 `"w"` 表示寫入；每次 `file.write()` 不會自動換行，所以加入 `"\n"`。

這個例子每次執行都會重新建立內容，因為使用的是 `"w"`。

## 再試一次：例子 2——讀回和追加一行

**先執行例子 1**，再執行以下程式：

```python
with open("study_notes.txt", "a", encoding="utf-8") as file:
    file.write("完成：第 44 課\n")

with open("study_notes.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

### 預期輸出

```text
閱讀：Python 變數
練習：for 迴圈
問題：甚麼時候用 List？
完成：第 44 課
```

`"a"` 在檔案尾加上一行。讀取時，每個 `line` 本身已帶有換行符號，所以顯示前使用 `strip()` 去除尾端換行。

## 易錯位

### ❌ 不小心用 `"w"` 覆蓋舊紀錄

**原因：** `"w"` 由頭開始寫，原本內容會消失。

**✅ 修正：** 想保留舊內容並加新紀錄時使用 `"a"`；重要檔案先備份。

### ❌ 忘記換行

連續 `write("第一項")` 和 `write("第二項")` 會黏在同一行。

**✅ 修正：** 在每一行文字後加入 `"\n"`。

### ❌ 沒有指定中文編碼

不同環境可能以不同預設編碼開啟檔案。

**✅ 修正：** 處理中文時固定寫 `encoding="utf-8"`。
