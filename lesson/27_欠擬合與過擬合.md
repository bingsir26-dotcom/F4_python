# 第 27 課：欠擬合與過擬合——不是越複雜越好

> **本課主題：比較模型在訓練資料和新資料上的表現，找出太簡單、太記住細節與較合適的情況。**
>
> 模型的目標不是背熟已有資料，而是遇到新資料時仍能作出合理判斷。這種能力叫作泛化。

## 今課可以做到甚麼？

- 看出訓練表現和測試表現可能不同；
- 分辨欠擬合、較合適與過擬合的基本特徵；
- 用 KNN 的 `n_neighbors` 比較不同程度的複雜度。

## 開始前：想一想

只背熟十題練習題，遇到題目稍微改變便不會做；另一方面，若只學到一條太粗略的規則，也未必能解答原本的題目。

模型同樣可能「學得太少」或「記得太死」。

## 新概念

### 1. 三種常見情況

- **欠擬合**：模型太簡單，連訓練資料的基本規律也抓不好；
- **較合適**：訓練和新資料的表現都不錯；
- **過擬合**：模型把訓練資料的偶然細節也記住，訓練表現很高，但新資料表現下降。

![同一批資料可出現太簡單、較合適、太貼近細節三種模型狀態](/images/lesson-27-underfitting-overfitting.svg)

### 2. 要同時看兩個分數

- **訓練分數**：模型回答它已看過資料的表現；
- **測試分數**：模型回答未見資料的表現。

若訓練分數遠高於測試分數，便要懷疑模型是否只記住訓練細節。

## 跟著做：例子 1——改變 KNN 參考的附近例子數量

```python
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

# 建立一份課堂用的彎月形分類資料
X, y = make_moons(n_samples=120, noise=0.25, random_state=7)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7, stratify=y
)

for neighbors in [1, 5, 25]:
    model = KNeighborsClassifier(n_neighbors=neighbors)
    model.fit(X_train, y_train)

    train_score = accuracy_score(y_train, model.predict(X_train))
    test_score = accuracy_score(y_test, model.predict(X_test))
    print(neighbors, train_score, test_score)
```

### 預期輸出／結果

每行依次顯示：`附近例子數量、訓練分數、測試分數`。

這組固定資料通常會看到：`n_neighbors=1` 的訓練分數非常高，但測試分數較低；`n_neighbors=5` 的測試表現較好；`n_neighbors=25` 又可能因規則太粗略而下降。

### 逐行解釋

`make_moons()` 只是在課堂上快速建立一份有彎曲規律的示範資料，不需要下載 CSV。

`n_neighbors=1` 幾乎只參考最接近的一筆，容易跟著訓練資料的小細節走；數值太大時，模型又會把太多不同情況混在一起。這不是每份資料都必定如此，但能用來觀察模型複雜度的影響。

## 再試一次：例子 2——只看一個設定的結果

**先執行例子 1**，再把以下程式加入最後：

```python
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)

print("訓練分數：", accuracy_score(y_train, model.predict(X_train)))
print("測試分數：", accuracy_score(y_test, model.predict(X_test)))
```

比較這兩個分數。它們不必完全相同；重點是不要只挑訓練分數最高的設定。

## 易錯位

### ❌ 只選訓練分數最高的模型

過擬合模型經常能在訓練集取得很高分，所以只看這個分數容易選錯。

### ❌ 以為複雜模型一定更強

複雜度增加能記住更多細節，但不代表那些細節會在新資料再次出現。

### ❌ 不斷用同一測試集調整設定

若反覆依測試集挑選參數，測試集也漸漸變成練習題。之後會學到更完整的驗證方法；現在先養成不只看一次分數的習慣。

## 本課小結

1. 欠擬合太簡單；過擬合太記住訓練細節。
2. 選模型要同時看訓練與未見資料的表現。
3. 複雜度不是越高越好，目標是泛化到新資料。
